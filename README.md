## 繁體中文

十六歲，語言遲緩，智力落後，三到五歲爆發癲癇、如今靠藥物穩定多年。外觀完全正常，基因檢測正常，生活自理完全獨立。他是特教班老師的小幫手，人緣極好；而他每天只想講兩件事——火車，還有六福村。

這本書寫給站在這個路口的家長與老師：**開發期已經過去了，轉銜期正在開始，而你手上只剩四年。**

它不談奇蹟，也不賣任何療法。它只做一件事：**把一個孩子最強烈的固著，改裝成他未來三十年的謀生工具**——把「反覆講火車」變成準時、守序、能等待；把「六福村門票 800 元」變成他真的會付錢、會收零錢、會看時刻表。

> 💡 **全書的核心命題**
> 不是把火車從他手裡拿走，而是**讓火車載他去上班**。

### 這套培育計畫長什麼樣

| 維度 | 設計哲學 |
|------|----------|
| **三大核心** | 神經控制力（把生氣換成「等一下」）、工作記憶鏈（一句話裝得下兩件事）、固著功能化（最愛的事變成本事） |
| **六大階段** | 國三上到高職畢業後，四年一條時間軸；每一階段有明確的入場條件與離站標準（DoD） |
| **可驗收** | 每個訓練都要能回答三件事：練哪一條神經、怎麼檢核、幾週內看得到什麼 |
| **不打壓固著** | 固著是動機引擎。所有教材都包在火車與遊樂園裡，孩子的抗拒成本最低 |
| **人在迴路裡** | 沒有任何一項訓練可以取代醫師、老師與家長的判斷；工具只負責把觀察變成數據 |

### 八篇結構

| 篇 | 內容 |
|----|------|
| **第一篇　認識這顆獨特的大腦** | 為什麼是他：病史還原、語言障礙基因地圖、鑑別診斷漏斗、可逆的那一小群、疫苗與因果、十六歲的定位（`01`–`06`） |
| **第二篇　三大核心** | 所有訓練共用的三條主軸，以及支撐它們的神經地基：藥物、腦波、睡眠、飲食與腸道（`07`–`11`） |
| **第三篇　六大階段** | 四年時間軸：奠基 → 轉化 → 職業探索 → 職場耐受 → 校外實習 → 社會轉銜，含每階段的可發展事項與離站標準（`12`–`20`） |
| **第四篇　教材與工具箱** | 十組火車主題功能性數學教材、逐字互動台詞、以及「為什麼面試考的是剪刀和抹布」（`21`–`27`） |
| **第五篇　轉銜與永續** | 方法學總則、三百種語言與認知提升法、給三歲家長的三十個方向、如何在 IEP 與鑑輔會把資源要到手（`28`–`34`） |
| **第六篇　專業補強** | 行為功能評估（FBA／ABC／FCT）、工作分析與連鎖、增強的技術、青春期與身體界線、危機處理與行為升級、十八歲的法律斷崖（`35`–`40`） |
| **第七篇　情境百景** | 五十個真實場景，每景七段拆解（背景／問題／需要的技能／可用工具／這本書怎麼做／沒有這套方法的窘境／效益）＋ 君之一席話 ＋ 進階點評：家庭日常、學校與班級、社區與交通、醫療與身體、職場與轉銜（`41`–`45`） |
| **第八篇　更複雜的情況** | 共病與診斷遮蔽、感官與內感受、重度與無口語的另一條路徑、女兒被忽略的那一半（`46`–`49`） |
| **附錄** | A 速查索引＋情境總索引 · B 資源速查 · **C 現實校準** · D 個案化附錄 · **E 家庭與三十年** · F 術語表 · **G 來源與延伸閱讀** |

每章採同一副建置書骨架：**背景與痛點 → 核心設計（含流程圖）→ 實作（逐步教案與逐字台詞）→ 現場踩雷 → 效益與驗收（DoD）**，末附一句「君之一席話」。

### 這本書給誰

- 家中有語言遲緩、智能障礙、自閉特質或癲癇病史孩子的**家長**，特別是孩子已經進入國中、高職的轉銜期；
- 帶特教班、資源班、或負責 IEP 的**老師與治療師**，需要一套能寫進個別化教育計畫、且**可檢核**的訓練設計；
- 想知道「這些訓練到底在練什麼、幾週能看到什麼、什麼時候該停手」的人。

第八篇補的是「不在主線上的家庭」：**診斷遮蔽**（症狀被歸因到原診斷，可治療的問題長年不被治療）、
**內感受**（他不知道自己餓了、累了、快生氣了——這解釋了為什麼他總是「突然」爆發）、
**部分參與原則**（做不到全部，仍可參與其中一格），以及**女兒**那被忽略的一半。

第七篇是**情境驅動**的：方法書教你「怎麼做」，情境百景處理的是「那件事發生的當下」——
他在超商門口不肯走、老師說「他今天情緒不好」、半夜兩點的發作、就服員打電話來。
五十景全部標了對應章節，可以只讀一景，需要時才翻回正文。

第六篇補上前五篇刻意省略的方法學：**行為的功能**（為什麼「所有方法都試過就是沒用」通常代表方向選錯）、
**工作分析**（「他學不會折衣服」其實是十一件事被當成一件事在教）、**增強的技術**、
**青春期與身體界線**（最該教、也最常被迴避的一課）、**危機處理**，以及**十八歲那天你在法律上不再是他的代理人**。

附錄 C 替你補上快樂路徑之外的現實校準——**六條讓訓練不傷人的鐵律**，以及一個誠實的數字：這套計畫改變的是**功能（能自己做到什麼）**，不是智商，也不是診斷。

### 怎麼建置與驗證

純 Python、無第三方依賴：

```bash
make build         # 產出 慢車到站.html（側欄目錄）＋ 慢車到站_全書.md
make check         # 書稿 + 工具包資產檢查（免安裝依賴，秒級）
make assets        # 產生列印用資產（檢核卡、代幣板、價格字卡、時刻表、工作分析步驟卡）
make mutate        # 變異測試：把已修復的缺陷逐一改回去，驗證測試真的抓得到
make ci            # CI 全套：再加上 impl 的 ruff + mypy strict + pytest（覆蓋率門檻 85%）
make pdf           # PDF（需在 Windows 端執行 `cmd.exe /c _make_pdf.bat`）
```

`make assets` 產出九張可列印的 SVG：五張教具卡（檢核卡、代幣板、價格字卡、時刻表、工作分析卡）
與**四張記錄表**（每日三指標、ABC 三聯式、睡眠日誌、偏好評估）。
記錄表刻意做成「一張紙一個月」——書中每章都給了表格範本，但真正每天要填的那幾張，
家長得自己畫格子，而「自己畫格子」是記錄中斷最常見的第一個原因。

`make check` 守住七件事：架構圖引用斷連、繁體書稿混入簡體字、**談藥卻沒帶醫療免責框**、
**真名漏進主線章節**（本書是雙軌：主線化名，個案細節只收在附錄 D）、建置產物與書稿不同步，
21 張 SVG 內嵌後的 HTML id 衝突，
**情境百景的七段骨架有沒有缺段、編號有沒有跳號**（五十景用同一副骨架，寫到第三十七景一定會漏——所以讓機器數）、
**術語表列了正文沒有的詞**，以及**「第 N 章」「附錄 X」的交叉引用是否真的存在**
（章號在補強過程中從 34 一路加到 49，而指向錯誤章節的引用，沒有自動化以外的方法能發現）。

資產側（`scripts/check_assets.py`）比對的是**書與工具有沒有走散**：書中十組教材的編號是否都在
`railway_core.curriculum` 註冊、每組是否真的寫在它宣稱的那一章、六站代號是否一致、離站標準引用的
指標名是否都登記在 `railway_core.tracking.METRICS`、`.env.example` 是否涵蓋程式讀取的每個環境變數，
以及**程式裡的紅旗清單與「永遠不要」是否與書稿一字不差**——因為讀者在書上看到的那一句，
和工具印出來的那一句，必須是同一句。

> **為什麼有 `make mutate`**：覆蓋率只回答「這一行有沒有被執行過」，不回答「它壞掉時有沒有人發現」。
> 這支腳本把 23 個開發過程中真的犯過的錯逐一改回去（`all([])` 是 True、`< 3` 寫成 `<= 3`、
> 沒量到的指標當成通過、ABC 的前事可以填「不知道」、SVG 不做跳脫…）。
> 首次執行時有 **7 個變異存活**——也就是七個「壞掉也沒人會發現」的行為；
> 補完測試後全數被抓。第六篇的工具上線後又抓到第八個，而那一個特別值得記下來：
> 測試用 `MIN_RECORDS_FOR_HYPOTHESIS - 1` 去構造測資，**用常數自己測那個常數**——
> 把門檻從 10 改成 1，測試照樣通過。現在門檻寫死在測試裡，因為它是規格（第 35 章）。
> 目前 26 個變異全數被抓（殺死率 100%）。演進紀錄見 [CHANGELOG.md](CHANGELOG.md)。

工具包 `impl/` 是**零依賴**的：只用 Python 標準庫，`python3 impl/selftest.py` 三秒可驗，
不需要 `pip install`。這與書的立場一致——第 21 章說全套教具一到兩千元就夠，那麼工具也不該
要求讀者先學會建虛擬環境。

流程圖與封面為自足 SVG（`diagrams/` 與 `cover.svg`），建置時直接內嵌進 HTML，**零外部資源、可離線**。

## English

He is sixteen. Speech delayed, cognition delayed, seizures that erupted between ages three and five and have been controlled by medication for years. He looks completely typical. His genetic panel came back normal. He dresses, eats and toilets entirely on his own. He is the special-ed teacher's favourite helper, and he wants to talk about exactly two things: trains, and one amusement park.

This book is for the parent or teacher standing at that crossroads: **the developmental window has closed, the transition window has opened, and you have four years.**

It sells no miracle and no therapy. It does one thing: **re-engineers a child's strongest fixation into the tool he will earn a living with** — turning "he keeps talking about trains" into punctuality, sequence and the ability to wait; turning "the park ticket costs NT$800" into a young man who actually pays, takes his change, and reads a timetable.

> 💡 **The central thesis**
> Don't take the train away from him. **Let the train carry him to work.**

Built as pure Python (no third-party deps): `python _build.py` merges the chapters into a single HTML (sidebar TOC) plus a merged Markdown. Diagrams and the cover are self-contained SVGs inlined at build time — fully offline.
