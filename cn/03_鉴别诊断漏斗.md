# 第3章　鉴别诊断的漏斗：当四个特征同时出现

![鉴别诊断漏斗：从排除可逆因素、判断落后范围、症候群性与否，到癫痫时间分水岭与检查配置](diagrams/d03_diagnosis_funnel.svg)

## 背景与痛点

「男孩、外观完全正常、语言迟缓、智力落后、三到五岁出现癫痫。」

这五个条件凑在一起的时候，家长会遇到一个特殊的困境：**每一位专业人员都只回答自己那一块，而没有人把整张图拼给你看。**

耳鼻喉科说听力没问题。复健科说要做语言治疗。小儿神经科说癫痫先控制住。遗传科说可以考虑做检测。特教老师说先办鉴定安置。每一句都对，但你回到家仍然不知道：**这五个特征到底是一件事，还是五件事？**

这一章给你那张图。它是一个漏斗——从最外层「可逆的、可治疗的、最不该漏掉的」开始，一层一层往内收。

> ⚠️ **医疗免责**
> 本章是**理解框架**，不是诊断流程，更不能拿来自我诊断或推翻医师判断。每一层该做哪些检查、什么时候做、要不要做，都由医师依孩子的实际状况决定。这一章的用途是：让你在门诊时听得懂、问得出、也记得住。

---

## 核心设计：四层漏斗

漏斗的顺序不是随便排的。它按照一个原则：**越上层，漏掉的代价越大。**

| 层 | 问题 | 为什么放在这一层 | 主要工具 |
|----|------|----------------|---------|
| **第 0 层** | 是不是「听不到、所以不会说」？ | 可完全矫正，漏掉等于白费数年训练 | 听力检查、中耳评估 |
| **第 1 层** | 是**单纯语言**落后，还是**全面**落后？ | 决定训练是「单科」还是「整体」 | 儿童发展联合评估 |
| **第 2 层** | 是症候群性，还是非症候群性？ | 决定要不要往全身系统排查 | 理学检查、外观特征、家族史 |
| **第 3 层** | 癫痫是**结果**，还是**凶手**？ | 决定治疗是否需要更积极 | 睡眠脑电图、脑部影像、基因、代谢 |

## 实作

### 第 0 层：先把「物理与环境」排除掉

这一层看起来最基础，却是最常被跳过的一层——因为孩子的外观正常，大人会直觉往「大脑问题」跳。

| 要排除的 | 为什么 | 怎么查 |
|---------|--------|--------|
| 听力损失、中耳积水 | 听损儿童外观完全正常；反复中耳积水会造成间歇性的传导性听损，孩子听到的是一段一段的语音 | 纯音听力检查、耳声传射、鼓室图 |
| 环境刺激不足 | 主要照顾者极少对话、长时间 3C、多语混杂输入 | 诚实回顾一日作息，不必羞愧，只需诚实 |
| 口腔动作结构问题 | 舌系带、腭裂等会影响构音（但不影响理解） | 口腔理学检查 |

**这一层的关键提问是：「他是听不到、听不清，还是听到了但解不开？」** 三种的处理完全不同。

### 第 1 层：单纯语言落后，还是全面落后？

| | 发展性语言障碍（DLD／SLI） | 全面性发育迟缓 |
|---|---|---|
| 智力（非语文） | 正常范围 | 落后 |
| 生活自理 | 符合年龄 | 落后 |
| 语言 | 明显落后 | 落后（与整体一致） |
| 训练重点 | 语言治疗为主轴 | **认知、注意力、动作先行**，语言随后 |

这一层决定了训练的重心。**如果是全面性落后，只做语言治疗的投报率会很低**——因为孩子不是「有想法说不出来」，而是连要表达的那个想法都还没成形。此时职能治疗（注意力、手眼协调）与认知训练必须同步进行，语言才推得动。

本书的个案属于后者：智力与语言双重落后，而生活自理反而发展得很好。这个组合本身就是重要信息——**它说明训练是有效的，只是过去主要作用在自理，而非语言。**

### 第 2 层：症候群性，还是非症候群性？

「外观完全正常」是本书个案最重要的一条线索。它把诊断可能性收敛了一大半。

在遗传性智能障碍合并癫痫的个案中，相当比例（常见估计约六到七成）**外观完全正常**——五官端正、骨骼正常、身材比例正常。这一群被称为**非症候群性**：突变只微观地影响大脑突触或离子信道，不影响外形发育。

外观正常时，临床上会优先考虑的方向：

**A. 男性特有的 X 染色体连锁疾病**
男性只有一条 X 染色体，该染色体上的关键基因一旦突变就直接发病。

- **脆折 X 症候群（FMR1）**：男性遗传性智力与语言落后**最常见**的原因。幼儿期外观往往完全正常（长脸、大耳等特征多在青春期后才明显），常合并过动、眼神接触差、语言重复。**这是男童几乎必查的一项。**
- **ARX**：影响 GABA 神经元发育，表现为智力落后合并严重语言障碍，外观无异常。
- **KDM5C**：明显认知障碍与表达性言语丧失，外观正常。

**B. 突触与离子信道的新发突变**
`SYNGAP1`、`GRIN2B`、`SLC6A1` 这一群。典型轨迹是：幼儿期中重度智力与语言迟缓 → **3 至 5 岁爆发癫痫** → 青春期后癫痫逐渐较好控制，但认知与语言障碍留下来。

这条轨迹与本书个案高度吻合。

**C. 隐性代谢疾病**
出生时完全正常，随毒素累积逐步侵蚀。这一群单独在第 4 章处理，因为**其中有极少数是可以治疗的**。

**D. 自闭症类群（ASD）**
外观正常，核心在社交沟通障碍与重复刻板行为。它不是上面三者的替代选项——**它可以与上面任何一项并存**，而且在本书个案身上，自闭特质确实与神经损伤同时存在（见第 5 章）。

### 第 3 层：癫痫是结果，还是凶手？

这是整个漏斗最关键、也最容易被误解的一层。

三到五岁这个时间点不是巧合。它是大脑神经网络快速复杂化的阶段，也是许多离子信道与突触基因异常「爆发」的高峰期。临床上会沿三个方向排查：

**方向一：发育性及癫痫性脑病（DEE）**
基因异常同时造成发育迟缓与癫痫——癫痫和迟缓是**同一个原因的两个结果**，而不是谁造成谁。

**方向二：癫痫-失语症谱系**
以兰道-克莱夫纳症候群（LKS）为代表。孩子在发病前语言可能大致正常或仅轻微迟缓，之后出现**听觉失认**——听力完全正常，却突然像听不懂人话一样，语言能力急速倒退。

这一群的关键在于：**放电多半发生在睡眠中**（睡眠期癫痫电状态，CSWS）。白天二十到三十分钟的常规脑电图，经常抓不到。

**方向三：代谢性疾病的晚发型**
三岁前毒素累积未达饱和，只表现为「太乖、不哭、轻微迟缓」；三岁后重创皮质，开始频繁发作与全面退化。这一群见第 4 章。

> 🔍 **这一层真正的重点，不是分类，是「有没有在偷走东西」**
> 癫痫性脑病最恶劣的地方，不是发作本身——发作看得见，你会送医。真正的伤害来自**持续性的异常放电，尤其是夜间的**。它像白蚁一样，安静地吃掉孩子原本具备的专注力、记忆与语言。
> 你看到的不是抽搐，是「他最近怎么变得特别暴躁」「原本会的怎么忘了」。

### 红旗清单：出现任何一项，当天就医

```text
【技能倒退】★ 最重要的一条
  □ 原本会叫的称呼不叫了
  □ 原本听得懂的指令听不懂了
  □ 原本会自己做的事（如厕、进食）退回需要协助
  □ 原本会说的词不见了

【发作型态改变】
  □ 发作形式和以前不一样（例如从失神变成全身僵直）
  □ 发作频率明显增加
  □ 单次发作超过 5 分钟，或连续发作之间意识没有恢复  → 叫救护车

【行为与意识】
  □ 白天异常嗜睡、叫不太醒
  □ 情绪突然变得极度暴躁或过动，且找不到环境原因
  □ 新出现的步态不稳、手抖、视力抱怨

【药物相关】
  □ 异常大量掉发、持续呕吐、皮肤出现红疹或黏膜溃疡
  □ 身上出现不明原因的瘀青或牙龈出血
```

最后两项与抗癫痫药物的已知不良反应有关（皮肤黏膜反应、血液与肝功能影响），一旦出现应立即联系主治医师，**不要自行停药**——突然停用抗癫痫药物可能诱发癫痫重积状态。

### 检查配置对照表

| 检查 | 主要回答的问题 | 什么情况下特别必要 |
|------|--------------|-----------------|
| 纯音听力／鼓室图 | 是不是听不到 | 任何语言迟缓，**第一步** |
| 儿童发展联合评估 | 落后是全面还是单科 | 学龄前必做；学龄后每次重新安置前 |
| 染色体芯片（CMA） | 有没有较大片段的重复／缺失 | 智能障碍合并多重异常 |
| FMR1（脆折 X） | 男性最常见的遗传性智能障碍 | **男童几乎必查** |
| 全外显子定序（WES） | 单点突变 | 上述皆正常、且结果可能影响用药时 |
| **睡眠脑电图** | 夜间是否仍在放电 | **怀疑退化、注意力恶化、情绪异常时** |
| 脑部磁振造影（MRI） | 结构异常（如局灶性皮质发育不良） | 难治型癫痫；一般 MRI 正常不代表没有 |
| 代谢筛检（血、尿） | 可治疗的代谢异常 | 见第 4 章 |

**表中最值得多说一句的是睡眠脑电图。** 常规脑电图与睡眠脑电图不是同一件事，前者正常不代表后者正常。当孩子出现「不明原因的注意力恶化、情绪暴躁、学习停滞」时，**问医师一句「需不需要安排睡眠脑电图」，是这一章最实用的一句话。**

## 现场踩雷

**踩雷一：跳过第 0 层。**
孩子外观正常又聪明伶俐，大人直接往「发展问题」跳，结果两年后才发现是反复中耳积水。这种案例并不罕见，而它是这个漏斗里唯一**完全可矫正**的一层。

**踩雷二：把自闭特质当成「另一个诊断」，于是二选一。**
「他到底是自闭症还是智能障碍？」——这个问句本身有问题。两者可以并存，而且在神经发育障碍里并存是常态。教学上也不需要二选一：自闭特质决定**怎么教**（结构化、可视化、可预测），认知落后决定**教到哪**（难度与步骤数）。

**踩雷三：常规脑电图正常就放心。**
如第 3 层所述。真正该问的是「这次做的是哪一种脑电图、有没有涵盖睡眠期」。

**踩雷四：把「发育倒退」当成叛逆或懒惰。**
青春期的孩子退步，大人的第一直觉常是行为问题。但在有癫痫病史的孩子身上，**倒退是神经信号，直到被证明不是为止**。顺序不能反过来。

**踩雷五：漏斗跑完就不再回头。**
漏斗不是一次性的。孩子每一次出现「说不出原因的退步」，都应该从第 0 层重新走一遍——听力可能后天变化，放电可能重新出现，药物浓度可能因体重成长而相对不足。

## 效益与验收（DoD）

| 项目 | 验收标准 |
|------|---------|
| 第 0 层已排除 | 一年内有正式听力检查纪录，结果正常或已处置 |
| 落后范围已界定 | 手上有一份发展评估报告，能说出是全面落后或单科落后 |
| 男童必查已完成 | 已做过 FMR1（脆折 X）检测，或医师明确表示不需要并说明理由 |
| 放电状态已确认 | 知道最近一次脑电图是**何时、哪一种**（常规／睡眠），以及结论 |
| 红旗已张贴 | 上方红旗清单印出来贴在冰箱或家庭群组置顶 |
| 认知一致 | 主要照顾者都同意：**技能倒退＝医疗事件，不是行为问题** |

最后一项是这一章最重要的产出。它未必会用到；但需要用到的那一天，它会决定反应速度是当天还是三个月后。

> 💡 君之一席话
> 「诊断这件事，家长最常犯的错不是查得不够，是**查得太集中在最下面那一层**。你为了那个还没找到的基因跑遍全台，而最上面那层——他这半年到底听不听得清楚——已经两年没有人量过了。」
