# 第4章　可逆的那一小群：先天性代谢异常与「要不要再验一次」

## 背景与痛点

第 2 章讲了一件让人泄气的事：**大多数基因诊断不会改变今天的教学。**

这一章要讲那个例外。

在所有导致智力落后、语言迟缓与幼儿期癫痫的病因里，有一小群是**先天性代谢异常**（Inborn Errors of Metabolism, IEM）——身体缺少某个酵素、辅酶或运输蛋白，导致无法正常获取能量，或无法排出代谢废物，毒素在大脑累积。

这一群的比例不高。但它有两个性质，让它值得单独占一章：

1. **其中极少数是可以治疗的。** 不是「改善」，是换一种饮食或补一种维生素，癫痫就控制住了、认知就不再退化。
2. **错过的代价是不可逆的。** 大脑被毒素侵蚀的部分不会回来。

换句话说，这是整份鉴别诊断里**期望值最不对称**的一格：几率低，但漏掉的损失极大。

> ⚠️ **医疗免责**
> 本章提到的生酮饮食、大剂量维生素治疗、特殊配方奶粉、蛋白质限制，**全部都是处方级的医疗处置**，必须由小儿神经科或新陈代谢／遗传专科医师评估后运行，并在营养师监控下进行。
> **自行尝试生酮饮食是危险的**：它会影响抗癫痫药物的代谢、电解质与生长，在没有适应症的孩子身上做，只有风险没有好处。这一章的用途是「知道要问什么」，不是「知道要做什么」。

## 核心设计：四类代谢疾病与它们的破坏方式

| 类型 | 破坏方式 | 代表疾病 | 关键特征 |
|------|---------|---------|---------|
| **毒素累积型** | 无法代谢的中间产物在脑部累积 | 苯酮尿症（PKU）、枫糖尿症（MSUD）、甲基丙二酸血症、丙酸血症 | 出生时正常；**发烧或感染后急性恶化** |
| **能量供应型** | 大脑拿不到燃料 | 粒线体疾病（如 MELAS）、**GLUT1 缺乏症** | 外观完全正常；发烧／饥饿后爆发 |
| **辅酶依赖型** | 缺少合成神经传导物质的关键辅酶 | **维生素 B6 依赖性癫痫** | ★ 一般抗癫痫药物**完全无效** |
| **储积型** | 大分子在细胞内堆积 | 溶体储积症、黏多糖症早期 | 早期外观无异常，**进行性退化** |

这张表里有两格加了星号，因为它们是「治疗方式完全不同」的两个：

**GLUT1 缺乏症。** 大脑的葡萄糖运输车坏了——血糖正常，但糖进不去大脑。孩子外观完全正常，表现为发展迟缓与各式各样的癫痫。治疗不是抗癫痫药，而是**生酮饮食**：让身体改烧酮体，绕过坏掉的运输蛋白，直接喂饱大脑。适应对的个案，效果可以是戏剧性的。

**维生素 B6 依赖性癫痫。** 缺少的是合成神经传导物质的辅酶。这类癫痫用常规抗癫痫药物压不住，必须用**大剂量维生素 B6**。它罕见，但它是所有难治型癫痫评估中必须被想到的一项。

这两者的共同点是：**如果不去想，就永远不会被发现**——因为孩子外观正常，常规检查也可能正常。

## 实作

### 一、三道防线（各自的时间窗口不同）

| 防线 | 时机 | 做什么 | 能避免什么 |
|------|------|--------|-----------|
| **第一道** | 孕前／产前 | 夫妻双方带因者筛检；已知家族史者可考虑产前诊断或胚胎着床前检测 | 避免**下一胎**发病 |
| **第二道** | 出生 48 小时 | 新生儿筛检（足跟血、串联质谱仪，一次可筛数十种） | 在**大脑受损前**拦截 |
| **第三道** | 已发病 | 确诊病因 + 特殊医疗干预（饮食控制、辅酶补充、避免代谢危机） | 阻止**继续**退化 |

第二道防线的意义值得多说一句：这类疾病的宝宝**出生时外观完全正常**。若能在大脑受损前发现并立即介入，孩子长大后的智力与语言，可以与一般人无异。台湾的新生儿筛检涵盖率极高，这是这个社会做过最划算的一项公共卫生投资。

而对于已经十六岁的孩子，能做的只剩第三道防线。这也是下一节要回答的问题。

### 二、十六岁了，还要再验一次吗？

这是本章真正要回答的问题。答案不是「要」或「不要」，而是一组判准。

**倾向「值得再问一次医师」的信号：**

```text
□ 有过「发烧或感染之后，状况明显变差且没有完全回来」的经验
□ 曾经出现过原因不明的意识改变、呕吐、极度嗜睡
□ 生长曲线异常（过矮、过瘦、或青春期发育明显落后）
□ 有肌肉无力、运动耐受力特别差、容易极度疲倦的表现
□ 抗癫痫药物效果一直不理想，或需要不断加药
□ 有进行性退化：原本会的东西，这几年慢慢不见了
□ 新生儿筛检当年项目较少（早年的筛检涵盖范围比现在小）
□ 家族中有不明原因的婴幼儿早夭、或类似表现的近亲
```

**倾向「代谢疾病可能性低」的信号：**

```text
□ 癫痫已用单一药物稳定控制多年，未曾难治
□ 没有进行性退化——能力是「停滞」而非「消失」
□ 生活自理能力持续进步（毒素累积型多半反向：能力逐年减少）
□ 生长、体能、耐力大致正常
□ 新生儿筛检报告正常，且当年涵盖项目完整
```

本书的个案落在第二组：药物控制稳定多年、自理能力持续进步、无进行性退化。**代谢疾病的可能性因此偏低**——但「偏低」不等于「不必问」。**在下一次回诊时把上面第一组清单念一遍给医师听，成本是三分钟。**

### 三、无论有没有代谢疾病，这一条都要记住

代谢异常的孩子最怕两件事：**长时间饥饿**与**发烧感染**。两者都会触发身体的分解代谢压力，组织大量分解、释放毒素，可能引发急性恶化。

而这条原则的实用价值远超过代谢疾病本身——**任何有癫痫病史的孩子，生病时的照护原则都与之相通**：

```text
【孩子生病（发烧／肠胃炎／食欲差）时的家庭原则】

1. 不要长时间禁食
   即使没食欲，也要少量多次补充含糖的液体（运动饮料、稀释果汁、
   米汤）。禁食超过数小时而完全没有热量摄取，是最该避免的状态。

2. 呕吐到喝不下 → 就医，不要在家硬撑
   喝不下＋持续呕吐＝需要静脉输液的信号。

3. 发烧要积极处理
   发烧本身会降低癫痫发作阈值。退烧药的使用请事先问过医师，
   把答案写在健康手册上，不要在半夜临时决定。

4. 抗癫痫药不能因为呕吐就自己停掉
   吐掉药该不该补一次、怎么补，事先问医师并写下来。
   ★「生病时的用药处置」是每次回诊最值得花两分钟确认的事。

5. 准备一张「急诊卡」
   放皮夹与书包各一张，内容见下。
```

### 四、急诊卡

孩子在急诊室最大的风险，是接手的医师不认识他。一张卡片能解决大部分问题。

```text
┌─────────────────────────────────────────────┐
│ 【紧急医疗信息卡】                            │
│                                             │
│ 姓名／生日／血型                              │
│ 身心障碍证明：类别、等级、证号                 │
│                                             │
│ 诊断：                                       │
│   癫痫（发病年龄：__ 岁）                     │
│   智能障碍／发展迟缓                          │
│                                             │
│ 目前用药：                                    │
│   药名 ______ 剂量 ______ 服药时间 ______     │
│   （★ 请勿自行停用；停药可能诱发重积状态）      │
│                                             │
│ 已知过敏／禁忌药物：______                     │
│ 曾做过的检查：EEG（__年__月）MRI（__年__月）   │
│              基因检测（__年__月，结果：___）   │
│                                             │
│ 平常发作型态：______________                  │
│ 平常发作时长：约 __ 分钟                       │
│ 家属应叫救护车的判准：发作 > 5 分钟             │
│                                             │

│   听得懂简单指令，说话以短句／单词为主           │
```

最后那一段「沟通提示」是很多家庭不会想到、但急诊人员最感谢的一段。**它把固着兴趣变成了医疗现场的镇定工具**——这是本书核心命题在最意外的地方的一次应用。

### 五、带去门诊的提问脚本

```text
1. 以孩子目前的表现，还有没有必要排查先天性代谢异常？
   （如果医师认为不必，请问是根据哪些表现排除的？）

2. 他当年的新生儿筛检，涵盖了哪些项目？当年没筛到、
   而现在有在筛的项目里，有没有值得补做的？

3. 生病、发烧、吃不下的时候，我在家里该怎么处理？
   什么情况下必须直接送急诊？

4. 如果呕吐把药吐掉了，要不要补服？怎么补？

5. 退烧药我可以用哪一种？有没有要避开的？
```

把答案写在健康手册的第一页。**这五个问题的答案，在半夜三点的价值，远高于任何一份基因报告。**

## 现场踩雷

**踩雷一：看到「生酮饮食有奇效」就自己开始。**
生酮饮食是处方级治疗，需要营养师计算、定期抽血监控，并且会与抗癫痫药物交互作用。在没有适应症（如 GLUT1 缺乏症、部分难治型癫痫）的孩子身上运行，只有风险。

**踩雷二：把「代谢疾病可能性低」读成「不用管饮食」。**
两件事无关。第 11 章会说明，饮食对这类孩子的意义在别的地方——血糖稳定度、药物副作用管理、肠道与体重。

**踩雷三：生病时「让他休息、先不要吃」。**
这是最直觉、也最该避免的一个做法。发烧＋禁食＋抗癫痫药吐掉，是诱发发作的经典组合。

**踩雷四：急诊卡做好了，但放在家里抽屉。**
放皮夹、放书包、拍照存在两位照顾者的手机里、传一份到家庭群组并置顶。用不到最好，用到的时候通常没空回家拿。

## 效益与验收（DoD）

| 项目 | 验收标准 |
|------|---------|
| 代谢排查已定案 | 已向医师问过「还需不需要排查代谢异常」，并知道结论的依据 |
| 生病原则已成文 | 家中有一份「生病时怎么办」的书面原则，含退烧药与补药处置 |
| 急诊卡已就位 | 皮夹、书包各一张；两位照顾者手机各有一张照片 |
| 禁食风险已认知 | 主要照顾者都知道「长时间完全不进食」是需要避免的状态 |
| 未自行实施饮食疗法 | 没有在未经医嘱的情况下运行生酮或蛋白质限制 |
