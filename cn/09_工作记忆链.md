# 第9章　核心二　工作记忆链：一句话里装得下两件事

![工作记忆链的四个难度维度与十六级升级阶梯](diagrams/d09_memory_chain.svg)

## 背景与痛点

「帮妈妈把碗拿到厨房。」——他做得到。

「帮妈妈把碗拿到厨房，**然后顺便**把客厅的卫生纸拿过来。」——他把碗放进厨房，然后站在那里，或者直接回房间了。

大人接下来会做的事，几乎是本能：走过去，说「卫生纸呢？我刚刚不是说要拿卫生纸？」

这句话里有两个问题。

**第一，他不是忘了，是根本没有装进去。** 工作记忆像是大脑里的一块暂存区，容量有限。当「碗」「厨房」「拿过去」占满之后，「卫生纸」这一项在他开始移动的那一刻就掉出去了。这不是态度问题，是容量问题。

**第二，那句提醒让这次训练归零。** 因为他最后确实拿到了卫生纸——在大人提醒之下。而大脑记住的是：不用记，反正妈妈会再说一次。

工作记忆链是这本书里**最直接对应未来职场能力**的一条核心。小作所的组长不会只交办一件事，庇护工场的流程不会只有一个步骤。**能不能记住两件事并依序完成，是「需要有人全程盯着」与「可以放手交办」之间的那条线。**

---

## 核心设计

### 一、四个难度维度（不要一次动两个）

工作记忆链的难度不是只有「几步」。它有四个独立的维度，而训练的铁律是：**一次只提高一个维度。**

| 维度 | 从 | 到 | 为什么难 |
|------|-----|-----|---------|
| **① 步数** | 1 步 | 2 步 → 3 步 | 暂存区容量 |
| **② 空间** | 同一个房间 | 跨房间 → 跨楼层 → 跨场所 | 移动本身会冲刷暂存内容 |
| **③ 连接词** | 无 | 「然后」→「并且」→「顺便」 | 每个连接词的语意负荷不同 |
| **④ 语序** | 顺向（先说先做的） | **逆向**（「在 A 之前先做 B」） | 需要先解码、再重排顺序 |

同时提高两个维度（例如「跨楼层」＋「三步」），失败率会急遽上升，而失败的经验会让孩子开始回避交办任务——那是最不划算的一种倒退。

> 🔍 **为什么「顺便」是最难的那个词**
> 「然后」是明确的时间序：做完 A，做 B。
> 「并且」是并列：A 和 B 都要做。
> 而「**顺便**」缺省了一个孩子多半没有的能力：**在移动路径上自行判断何时插入第二个任务**。它不只要求记住，还要求规划。
> 所以「顺便」不是第三个同义词，它是一个**明显更高的阶级**。很多家长无意间第一次就用了它，然后得到一个看起来「不听话」的孩子。

### 二、十六级升级阶梯

把四个维度组合成一条可以照着走的路。每一级的通过标准都是：**连续五次交办，至少四次无额外提醒完成。**

| 级 | 内容 | 范例 |
|----|------|------|
| 1 | 同室・1 步 | 「把碗放到水槽。」 |
| 2 | 同室・2 步・「然后」 | 「把碗放到水槽，然后把抹布挂好。」 |
| 3 | 同室・3 步・视觉卡辅助 | 三格检核卡：擦桌子 ▢ 收碗 ▢ 关灯 ▢ |
| 4 | 同室・3 步・无卡 | 同上，但不给卡 |
| 5 | 跨室・1 步 | 「去客厅拿卫生纸过来。」 |
| 6 | 跨室・2 步・「然后」 | 「把碗拿到厨房，然后去客厅拿卫生纸。」 |
| 7 | 跨室・2 步・「并且」 | 「把联系簿交给老师，并且把抹布带回来。」 |
| 8 | 跨室・3 步 | 三个地点、三件事 |
| 9 | 跨室・2 步・**逆向语序** | 「**在拿抹布之前**，先把本子交给老师。」 |
| 10 | 跨场所・2 步 | 「去超商买牛奶，然后把发票拿回来给我。」 |
| 11 | 跨场所・2 步・含条件 | 「如果没有鲜奶，就买豆浆。」 |
| 12 | 延迟运行・1 步 | 「等一下吃完饭，去把垃圾拿出去。」（间隔 15 分钟） |
| 13 | 延迟运行・2 步 | 同上，两件事 |
| 14 | 中断后回归 | 运行到一半被打断，能自己回到原任务 |
| 15 | 自行规划顺序 | 「这三件事今天做完，顺序你自己决定。」 |
| 16 | 跨日任务 | 「明天早上出门前，记得带回条给老师。」 |

多数十六岁的孩子起点在第 1–3 级之间。**四年走到第 10–12 级，就足以支撑小作所的日常作业。**

### 三、提示褪除：独立率上不去的真正原因

「他做得到啊，只是我要在旁边提醒。」——这句话里藏着整条核心最大的陷阱。

行为训练上，「提示」是有层级的。训练的目标不是「让他完成」，而是**逐层拿掉提示**：

```text
提示强度   由强到弱
  ①  肢体协助（手把手带着做）
  ②  示范（大人先做一次给他看）
  ③  口头完整指令（「把碗拿到厨房，然后拿卫生纸」）
  ④  口头部分提示（「碗放好了，接下来呢？」）
  ⑤  手势提示（指一下客厅的方向）
  ⑥  视觉提示（检核卡、图卡）
  ⑦  无提示（自主启动）   ← 目标
```

大人最常犯的错，是**在孩子卡住的三秒内就跳回 ③**。而正确的做法是**先往下降一阶**：

```text
他卡住了（站在厨房不动）
  ↓ 等 5–10 秒（★ 这几秒最难忍，但它是训练的核心）
  ↓ 仍不动 → 给 ⑤ 手势提示（指客厅）
  ↓ 仍不动 → 给 ④ 部分提示（「还有一个东西喔」）
  ↓ 仍不动 → 给 ③ 完整指令，并记下：本次为完整提示
```

**那五到十秒的沉默，是工作记忆真正被使用的时刻。** 大人一开口，那段运算就被取消了。

## 实作

### 一、交办脚本（每天两次，一次不超过三分钟）

```text
【步骤 1】取得注意力（★ 不要对着背影说话）
  走到他面前，等他眼神看向你。必要时轻声叫名字，等 2 秒。

【步骤 2】下达指令（短、慢、名词清楚）
  「碗拿到厨房，然后拿卫生纸。」
  ✗ 不要说：「你可以顺便帮妈妈把那个卫生纸拿一下吗，
             就是客厅那个，然后碗也要记得拿去厨房喔。」
  → 一句指令 ≤ 12 个字，名词放在句尾（最后听到的最容易留住）。

【步骤 3】覆诵（★ 这一步让成功率大幅提高）
  「你说一次。」
  他：「碗、厨房、卫生纸。」
  → 不必说出完整句子，能覆诵关键名词就算通过。
  → 覆诵的动作把「听觉输入」转成「自己的语音输出」，
    这在记忆上是完全不同的一件事。

【步骤 4】放手（大人转身去做自己的事）
  不要站在旁边看。被盯着会让他改成看你的脸色，而不是用自己的记忆。

【步骤 5】结果处理
  完成 → 具体称赞：「两件事都做到了，很厉害。」（不要只说「好棒」）
  卡住 → 走褪除阶梯（见上），并记录本次用到的提示层级
```

### 二、视觉检核卡：把暂存区搬到卡片上

工作记忆容量不足时，最有效的补偿不是「多练记忆」，是**把记忆外部化**。这也是所有小作所与庇护工场的标准作业方式——**这一招不是辅助轮，它就是职场现场的真实工作模式。**

```text
【火车联结任务卡】（A4 护贝，魔鬼毡可换图卡）

  ┌──────────┬──────────┬──────────┐
  │ 车厢 1    │ 车厢 2    │ 车厢 3    │
  │ [图] 擦黑板│ [图] 排桌椅│ [图] 倒垃圾│
  │    ▢      │    ▢      │    ▢      │
  └──────────┴──────────┴──────────┘
        ↑ 完成一项，自己用彩色笔打一个勾

【三个设计要点】
  1. 图卡用「实物照片」，不要用线条插图或纯文本
     → 视觉辨识速度差很多
  2. 打勾必须由孩子自己做，大人不能代打
     → 打勾这个动作本身，就是「完工」的神经标记
  3. 全部打完才交还卡片，换取下一件事（下课／点心／火车时间）
     → 卡片是凭证，不是提醒
```

### 三、逆向语序训练（第 9 级，难度陡增）

```text
【三阶段练法】

阶段 A（配图卡）：
  桌上放两张图卡，依实际运行顺序由左至右排好。
  「在拿抹布之前，先把本子交给老师。」
  → 请他把图卡「按照要做的顺序」排一次，再去运行。

阶段 B（口语 + 覆诵）：
  同一句话，不给图卡，但要求覆诵：「先做什么？再做什么？」

阶段 C（纯口语）：
  直接运行。

★ 逆向语序卡住是正常的，不代表退步。
  它刺激的是语意重排能力，是这条核心里最高端的一项。
```

### 四、记录

```yaml
# c2-progress.yaml
week: 2026-W12
core: C2

chain_length_max: 2          # 目前稳定的步数
current_level: 6             # 十六级阶梯的第几级
level_pass_rate: 0.6         # 本级连续 5 次中成功 3 次 → 未达标（需 4/5）

prompt_level_used:           # 本周各层级提示使用次数（越往 ⑦ 越好）
  full_verbal: 4             # ③ 完整口头
  partial_verbal: 3          # ④ 部分提示
  gesture: 5                 # ⑤ 手势
  visual_only: 6             # ⑥ 仅视觉卡
  none: 2                    # ⑦ 无提示

independent_task_rate: 0.44  # 上周 0.35

notes: |
  「顺便」这个词出现时失败率明显较高 → 本周起全面改用「然后」。
  跨室任务在放学后（较疲累）成功率低 → 移到早上做。
```

最后那两行是这份记录真正的价值：**它把「他做不到」变成「在什么条件下做不到」**，而后者是可以调整的。

## 现场踩雷

**踩雷一：用提醒把任务救回来。**
救回来的是那一次的家事，赔掉的是那一次的训练。**如果今天的目的是让事情完成，就直接自己做**（那完全没问题）；如果今天的目的是训练，就要忍住不提醒。**先决定今天是哪一种，不要两者都想要。**

**踩雷二：一次提高两个维度。**
「跨楼层＋三步」是经典的失败组合。四个维度，一次动一个。

**踩雷三：把「忘记」解读成「不听话」。**
在这条核心上，这是最伤人的一种误解。孩子没有拒绝你，他只是暂存区满了。**用「几步」来描述问题，而不是用「态度」。**

**踩雷四：任务内容没有意义。**
「把这叠纸从左边搬到右边，再搬回来」——这种为练而练的任务，孩子很快就会抗拒，因为大脑知道它没有结果。
**所有工作记忆训练都应该内置在真实家务或小帮手任务里**，让完成有真实的后果（桌子真的干净了、老师真的收到了）。

**踩雷五：只在家里练。**
在家练到第 8 级，到了学校还是第 2 级——因为情境没有类化。**同一级的任务要在至少两个场域（家、学校）各练过**，才算真的通过。这需要与老师同步，第 34 章提供沟通备忘录的范本。

**踩雷六：站在旁边看。**
被注视时，孩子会改用「读大人表情」来完成任务，而不是用记忆。训练必须有一段「大人不在视线内」的时间。

## 效益与验收（DoD）

| 项目 | 验收标准 |
|------|---------|
| 阶梯定位 | 明确知道目前在十六级的第几级，并有连续 5 次的通过纪录 |
| 覆诵已内化 | 交办时孩子能主动覆诵关键名词，或在一次提示下覆诵，达 ≥ 70% |
| 提示已褪除 | 「无提示 + 仅视觉卡」的比率较四周前提高，且「完整口头」比率下降 |
| 独立完成率 | `independent_task_rate` 较基线提高 ≥ 0.15 |
| 检核卡上线 | 三格任务卡实际使用满四周，打勾由孩子自己完成 |
| 跨场域 | 至少一级的任务同时在家庭与学校达标 |
| 记录可读 | 周记录中含「在什么条件下失败」的观察，而非只有成功／失败 |

> 💡 君之一席话
> 「他站在厨房不动的那五秒钟，是你最想开口的五秒钟，也是他大脑唯一在锻炼的五秒钟。**你每提醒一次，就替他做完一次；替他做完一百次，他就永远停在一步。**」
