# 第10章　核心三　固着功能化：火车不是症状，是动机引擎

![固着功能化的三个动作：限时、结构化、外壳化，以及外壳式与酬赏式的差异](diagrams/d10_fixation_engine.svg)

## 背景与痛点

有两种家长。

**第一种**带着孩子去亲戚聚会，孩子开始讲火车。第三次的时候，亲戚的表情变了。第五次的时候，家长打断他：「好了好了，不要再说了。」孩子沉默，或者生气。回家的路上，家长很累，而且有一种说不出口的难堪。

**第二种**在同一个场合，对亲戚说：「他很懂火车喔，你问他自强号和区间车差在哪里。」孩子讲了三分钟，亲戚说「哇你好厉害」，孩子笑了。

同一个孩子，同一个固着，两种完全不同的社会结果。

差别不在于固着的强度，而在于**它有没有被装进一个有用的形状里**。

而这件事有急迫性。固着在小学阶段，同学多半会包容；到了高职和成年，包容度会急速下降。一个一直重复同一个话题的成年人，很快会被边缘化——**他最大的资产（人缘）会被他最强的特质（固着）吃掉。**

这一章要做的，就是在那件事发生之前，把固着改装成三样东西：**边界、结构、外壳。**

## 核心设计

### 一、为什么固着是引擎，而不是垃圾

从训练的角度看，固着兴趣有三个极稀有的性质：

| 性质 | 意义 |
|------|------|
| **动机极高** | 不需要外部酬赏，他自己就会投入 |
| **抗拒极低** | 包上这层壳，同样的任务他愿意坐下来做 |
| **内容稳定** | 不像一般孩子的兴趣两周就换一个，它可以用四年 |

在一个「什么都推不动」的训练现场，这三个性质加起来，是唯一还在运转的引擎。

而更关键的是：**你没有办法创造它。** 你可以设计课程、可以买教材、可以请治疗师，但你无法让一个孩子突然对某件事产生这种强度的兴趣。它是天生的，它已经在那里了。

把它压掉，是这条路上最贵的一个决定。

### 二、三个动作：限时、结构化、外壳化

处理固着不是「压抑 vs 放任」的二选一。它是三个独立的动作，可以同时进行。

| 动作 | 做什么 | 解决什么 | 对应章节 |
|------|--------|---------|---------|
| **① 限时** | 给固着明确的时间框与代币 | 保护人缘、创建场合概念 | 本章 + 第 8 章 |
| **② 结构化** | 把碎念升级成有头有尾的叙述 | 实质提升口语组织能力 | 本章 |
| **③ 外壳化** | 把要练的能力包进火车主题里 | 降低抗拒、提高练习量 | 本章 + 第四篇 |

三者的顺序建议是 ① → ③ → ②：先有边界（否则什么都谈不了），再用外壳把训练量做起来，最后才慢慢提高叙述的结构要求。

### 三、外壳式 vs 酬赏式：一个必须讲清楚的区别

这是本章最重要的一段，因为两者看起来很像，效果却相反。

| | **外壳式**（建议） | **酬赏式**（谨慎使用） |
|---|---|---|
| 做法 | 把火车变成**任务本身的材料** | 做完不喜欢的事，**才给**火车 |
| 例子 | 「自强号 400、区间车 150，哪个贵？」 | 「作业写完，才可以看火车视频」 |
| 孩子的体验 | 我在玩火车，顺便算数 | 我在做讨厌的事，为了换火车 |
| 长期效果 | 学习本身变得可接受 | 学习被标记为「讨厌的事」 |
| 对固着的影响 | 固着被扩充、被赋予功能 | 固着被强化成唯一的价值来源 |

**外壳式不是不能用酬赏，而是酬赏不该是主要机制。** 一个健康的配置大约是：八成的训练用外壳式包装，两成可以用固着时间当作完成后的正常奖励（因为现实生活本来就有「做完事才休息」的结构）。

> 🔍 **一个检查方法**
> 问自己一句：**「如果拿掉奖励，他还会做吗？」**
> 外壳式的答案通常是「会，因为那本来就是火车」；酬赏式的答案通常是「不会」。
> 这个问题也能提前告诉你，这套训练在你不在场的时候还能不能运作——而在小作所里，你不会在场。

## 实作

### 一、对话代币制：把边界变成看得见的东西

```text
【家庭版】
  每天发 3 张「火车聊天券」（护贝小卡，可以印火车图案）。
  规则：
    · 一张券 = 5 分钟，且必须「交出券」才开始
    · 券用完了，今天的火车时间就结束（★ 不通融、不预支）
    · 未使用的券不累积到明天（避免囤积造成的谈判）
    · 大人在券的时间内必须「真的陪」——放下手机、认真听

【学校版】（请老师协助，第 34 章有给老师的备忘录范本）
  每天 3 张券，且限定在下课时间、对方同意时使用。
  非约定时间他提起 → 老师温和坚定地说：
    「现在不是火车时间，请把券收好。」
  → 这句话要固定、每次一样。不同的说法会被大脑当成不同的规则。

【代币的位置很重要】
  券要放在他看得到的地方（磁铁吸在白板上、或挂在书包侧边）。
  非使用时段他想讲时，大人一个字都不用说，只要用手指向那些券。
  → 看到实体代币，比听到一句拒绝，接受度高很多。
```

> ⚠️ **代币制的三个禁止**
> **不可以**把券当处罚工具没收（「你不乖，扣一张券」）——那会把它从结构变成惩罚，孩子会开始防卫。
> **不可以**在他情绪好的时候多给——规则的价值来自不变。
> **不可以**在他快要爆发时提前给——那是在教「情绪可以换券」。

### 二、结构化：把碎念升级成叙述

限时之后，那十五分钟要拿来做什么？不是被动听完，而是**引导他把内容组织起来**。

```text
【引导四问】（每次火车时间用其中 1–2 个，不要全部用）

① 数量框架：「你今天要介绍几个？我们讲三个好不好？」
   → 给大脑一个容器。有容器，内容才会被排序。

② 序数提示：「第一个是什么？」「那第二个呢？」
   → 序数是叙述结构最便宜的鹰架。

③ 比较框架：「自强号和区间车，哪里不一样？」
   → 比较会逼出属性描述（快／慢、贵／便宜、停几站）。

④ 收尾提示：「所以你最喜欢的是哪一个？为什么？」
   → 训练「结论」这个概念，这是叙述能力的高端项目。

【评分：什么叫「有结构」】
  0 分：单句重复（「自强号比较快」× N 次）
  1 分：能列出 2 个以上不同的内容
  2 分：内容有顺序（第一、第二）
  3 分：有开头、有内容、有结尾（「我讲完了」）

  → 记录每次的分数，计算 fixation_structured_ratio
    （得 2 分以上的次数 ÷ 总次数）
```

**这一段的价值容易被低估。** 对一个口语表达受限的孩子来说，「把一件事讲成三点」是很高端的语言能力——而他愿意在火车主题上做这件事，却不愿意在任何其他主题上做。**这是唯一的入口。**

### 三、外壳化四步骤：把任何能力包进火车

```text
【步骤 1】先写出你真正要练的能力（不要写「数学」，要写具体动作）
  例：「能从两个数字中指出比较大的那一个」

【步骤 2】在固着主题里找一个「天然含有」这个能力的场景
  例：票价、车速、车厢数、身高限制、时刻、月台号码

【步骤 3】用真实素材，不要用自制的假素材
  例：真的去印一张台铁票价表，不要自己画两个框写数字
  → 真实素材有两个好处：动机更高，而且能力可以直接类化到现场

【步骤 4】设计一句「他能听懂的交互台词」，且台词里要有角色
  例：「维修长！今天我们要出车。150 和 400，哪一张票比较贵？」
  → 角色称号（维修长、站长、小帮手）会大幅提高配合度，
    因为它把「被要求」转换成「扮演」。
```

第四篇整篇就是这四个步骤的十组完整示范。

### 四、社会化：从自我封闭到社交资产

固着功能化的最后一哩路，是让它变成**与人链接的媒介**，而不是隔开人的墙。

```text
【三个可以立刻做的做法】

① 「一张照片」规则
   每周准许他带一张自己选的火车照片到学校，
   在下课时给同学看，并练习一句固定台词：
     「这是我最喜欢的自强号，给你看。」
   → 重点是「给你看」而不是「听我讲」——前者是双向的。

② 「你呢？」的轮流练习
   在家庭火车时间里，大人也讲一件自己的事（30 秒就好），
   然后教他问一句：「你呢？」
   → 轮流是社交对话的最小单位，而它可以在最舒服的主题上练。

③ 专家角色
   在亲戚、邻居面前，主动把他介绍成「这方面他很懂」，
   并给对方一个具体问题（「你问他自强号跟区间车差在哪」）。
   → 这一招同时修复了大人的社交尴尬与孩子的自我价值。
```

### 五、意外的用途：固着是最好的镇定工具

在陌生、焦虑、疼痛的场合——抽血、看牙医、换新环境、实习第一天——固着兴趣是**现成的、免费的、随身携带的**安抚工具。

```text
【就医版脚本】
  候诊时：「等一下医生看完，我们去看火车。」（明确的奖励在等待之后）
  进诊间：让他手上握着火车玩具或火车卡片
  抽血时：「你数，这班车有几节车厢？」（把注意力导向可预测的内容）
  结束后：立刻兑现承诺（★ 一次不兑现，往后全部失效）
```

第 4 章的急诊卡上有一栏「沟通提示」，写的就是这件事。**当你把它写给急诊医护时，你不只是在帮孩子，你也在帮那位素昧平生、需要在三十秒内安抚一个陌生青少年的人。**

## 现场踩雷

**踩雷一：把固着压到地下。**
高压禁止的结果通常不是消失，是转入私下——孩子躲起来自己讲。表面上安静了，实际上你**失去了观测与引导的管道**，而固着本身一点也没少。

**踩雷二：无限奉陪。**
另一个极端。因为心疼、因为内疚，于是不设任何边界。结果是人缘被消耗、场合概念没有创建，而且到了机构里没有人有义务陪他讲九十分钟。

**踩雷三：外壳用到烂。**
所有东西都是火车，连续三个月，孩子开始厌倦——固着兴趣也会疲乏。
**解法：** 保留一到两成的「素面任务」（没有包装的一般任务），并在固着主题内部做变化（火车→铁道→车站→时刻表→售票→月台广播）。

**踩雷四：拿走他的固着当处罚。**
「你不听话，这礼拜不准讲火车。」——这会把引擎当成人质。短期可能有效，长期会让他把固着藏起来，并且让大人变成威胁来源。

**踩雷五：只有妈妈会用这一套。**
爸爸觉得「干嘛陪他讲那些有的没的」，老师觉得「这样会不会太宠」。结果孩子在不同人面前有不同规则，而规则不一致正是焦虑的来源。
**解法：** 第 34 章的备忘录范本，就是为了解决这一件事。

## 效益与验收（DoD）

| 项目 | 验收标准 |
|------|---------|
| 边界已创建 | 代币制实施满 4 周；非约定时段的固着发话，能以「指向代币」处理 ≥ 70% |
| 时间框稳定 | 固着话题有 ≥ 80% 发生在约定时段内（总时长不设上限） |
| 结构化 | `fixation_structured_ratio` ≥ 0.5（一半以上的火车时间能讲到 2 分以上） |
| 外壳化已上线 | 至少 3 项训练任务已改成火车主题外壳，并实际使用 |
| 社交化 | 「一张照片」或「你呢？」至少一项实施满 4 周，且有 ≥ 3 次正向同侪回应 |
| 镇定工具 | 至少一次在陌生或医疗场合成功使用固着兴趣安抚 |
| 没有被当人质 | 最近 4 周内，没有把「不准讲火车」当成处罚使用过 |

> 💡 君之一席话
> 「别人看到的是一个一直在讲火车的孩子；你要看到的是**一台已经发动、而且只认得一种燃料的引擎**。你的工作不是熄火，是接上传动轴。」
