# 第13章　阶段一　奠基期：把规则从嘴巴移到墙上

**对应时程：** 国三上学期（或任何起点的第一个学期）
**主核心：** C1 神经控制力
**这一站要交出的东西：** 一张看得懂的检核卡、一个会消失的红色、一个闭得住嘴的大人

---

## 背景与痛点

奠基期的敌人只有一个：**口头催促**。

一天下来，一个孩子平均会听到多少句催促？「快一点」「你在干嘛」「不是说要去洗手吗」「还有一个没做」「我刚刚讲过了」。

这些句子每一句都合理，加起来却造成三个后果：

1. **孩子学会等提醒。** 既然总会有人再说一次，何必自己记？
2. **大人的声音变成背景噪音。** 讲太多次的话会失去信号价值。
3. **每一次催促都是一次人际摩擦。** 一天二十次，一年七千次。

奠基期做的事，是把规则从**大人的嘴巴**搬到**墙上、卡片上、计时器上**。

这一步的价值不只在家里。**台湾所有的小作所、庇护工场、日照中心，用的都是同一套模式：SOP 图卡、工作检核表、打勾、计数。** 一个现在就习惯「看卡工作」的孩子，四年后报到的第一天就已经会了。

---

## 核心设计：三个步骤

| 步骤 | 做什么 | 对应核心 |
|------|--------|---------|
| **① 地基维护** | 用药规律、睡眠、放电状态确认 | 地基（第 11 章） |
| **② 任务可视化** | 小帮手任务改成三格检核卡，取消口头催促 | C1 + C2 |
| **③ 固着物理隔离** | 视觉计时器 + 对话代币，给固着一个看得见的框 | C1 + C3 |

三步骤的顺序不能换：地基不稳，后面两步都会被生理状态淹没。

---

## 实作

### 步骤①：地基维护

```text
【开学第一个月要完成的三件事】
  1. 回诊一次，带第 11 章的「回诊四段信息」
  2. 创建固定的服药时间点，并与生活作息绑定
     （绑在固定事件上，比绑在时钟上更不容易忘：例如「早餐后」「洗澡后」）
  3. 创建睡眠日志两周，并把固定起床时间先稳住
```

> ⚠️ **医疗免责**
> 服药时间、剂量、能否随餐、忘记吃该不该补、以及要不要安排任何检查（含睡眠脑电图），**全部由主治医师决定**。本节只提醒你把「规律」这件事在家庭端做好，并在回诊时主动报告观察到的变化。抗癫痫药物不可自行停用或增减。

**规律为什么重要，值得说一句：** 药物浓度的稳定，仰赖服药时间的规律。这是家庭端唯一能贡献、而且贡献很大的一环——它不需要任何医疗知识，只需要一个闹钟和一个习惯。

### 步骤②：三格检核卡（本阶段的主角）

**制作规格：**

```text
【材料】A4 纸、护贝膜、魔鬼毡、可擦拭彩色笔、实物照片

【版面】
  ┌────────────┬────────────┬────────────┐
  │  车厢 1     │  车厢 2     │  车厢 3     │
  │ [实物照片]  │ [实物照片]  │ [实物照片]  │
  │  擦黑板     │  排桌椅     │  倒垃圾     │
  │    ▢       │    ▢       │    ▢       │
  └────────────┴────────────┴────────────┘
   ← 卡片底色用他喜欢的主题（火车／游乐园）

【五个设计要点】
  1. 用「实物照片」，不要用插图或纯文本
     → 拍下他学校里真正的那块黑板、那个垃圾桶
  2. 图卡用魔鬼毡，可以每天更换
     → 任务会变，卡片不用重做
  3. 只放三格。不要四格、不要五格
     → 三格是起点。做稳了再谈第四格（第 9 章第 3 级）
  4. 打勾由孩子自己做，大人不能代打
     → 打勾这个动作本身就是「完工」的神经标记
  5. 卡片是凭证：三格打完，交还卡片，换取下一件事
     → 下课、点心、火车时间
```

**现场流程（给老师与家长的同一套）：**

```text
1. 交办时：不说长句。把卡片和笔交到他手上，手指第一格。
   （可以说一句：「三个车厢，做完打勾。」）
2. 运行中：不催促。站远一点，或去做自己的事。
3. 卡住时：走第 9 章的提示褪除阶梯，先等 5–10 秒。
4. 完成时：他把卡片交回来 → 具体称赞：
   「三个都打勾了，你自己做完的。」
   （不要只说「好棒」；要说出他做了什么）
```

### 步骤③：固着的物理隔离

完整的 SOP 在第 8 章（视觉计时器五步骤）与第 10 章（对话代币制）。奠基期只要求做到最基本的版本：

```text
【最小可行版本】
  · 放学后有一段「火车时间」，用视觉计时器框起来（建议 15 分钟）
  · 开始前预告，结束时只用手势，不用嘴巴
  · 前两周会变糟（消退爆发），不改规则

【这一阶段还「不需要」做的】
  ✗ 不需要一天三张券的完整代币制（S2 再上）
  ✗ 不需要要求他把火车讲得有结构（S2 再上）
  ✗ 不需要学校端同步（能同步最好，但不是本阶段的门槛）
```

### 每周五的三个观察指针

```text
① 情绪回复时间
   从被打断到配合下一件事，中位数是几分钟？
   目标：从基线缩短 30%，或稳定进入 2 分钟内

② 无提示任务完成度
   看着检核卡，中途不需口头提醒，能连续完成几项？
   目标：稳定完成 2 项以上

③ 药物与身体观察
   体重、掉发、手抖、白天嗜睡（第 11 章的观察表）
   目标：有记录；异常时已联系医师
```

### 饮食：这一阶段只做两件事

第 11 章已经说明过各项建议的证据等级。奠基期不要一次改十件事，**只做这两件**：

```text
1. 拿掉日常含糖饮料（手摇饮、含糖汽水、含糖茶饮）
   → 改成水、无糖茶、鲜奶。这一项对情绪稳定的效益最直接。
2. 三餐规律，不要长时间空腹
   → 尤其是早餐。空腹的下午，行为纪录通常最难看。

（其他的——低 GI 主食、深海鱼、补充品——留到 S2 以后，
  或直接与营养师讨论。一次改太多，一项都撑不住。）
```

## 现场踩雷

**踩雷一：卡片做得很漂亮，但大人还是一直讲话。**
这是最常见的失败。**卡片不会取代催促，除非大人真的闭嘴。** 建议做法：前两周，家长自己也给自己一张纪录卡，记下「今天我催了几次」。

**踩雷二：一开始就四格、五格。**
三格。三格。三格。

**踩雷三：大人代替孩子打勾。**
「他忘记打了我帮他打」——那一格就白做了。

**踩雷四：任务是假的。**
「把这叠纸搬过去再搬回来」——没有真实结果的任务，孩子很快会知道。**用真的家事、真的班务。**

**踩雷五：消退爆发时放弃。**
第 8 章讲过，这里再说一次：前一到两周抗拒会上升，那是介入生效的信号。**这时候妥协一次，比从来没开始还糟。**

**踩雷六：把奠基期做成「什么都练」。**
这一站只有三件事。第 21 章的数学教材、第 16 章的抗干扰训练，**现在都不要碰**。

## 离站标准（DoD）

**全部达成且连续两周稳定，才进入 S2。**

| 项目 | 标准 |
|------|------|
| 情绪回复时间 | 中位数 ≤ 2 分钟，或较基线下降 ≥ 30% |
| 无提示完成 | 看检核卡连续完成 **2 项以上**，中途无口头提醒，达成率 ≥ 70% |
| 打勾自主 | 三格打勾 100% 由孩子自己完成 |
| 手势制止 | 成功率 ≥ 80%（第 8 章第一阶） |
| 大人一致 | 两位照顾者最近两周无「当场妥协」纪录；口头催促次数明显下降 |
| 地基 | 睡眠日志完成；固定起床时间达成率 ≥ 70%；已完成一次回诊 |
| 饮食 | 日常含糖饮料已移除；三餐规律 |

**没过就留站。** 留在 S1 半年，比带着松动的地基去 S2 好得多。

> 💡 君之一席话
> 「你以为奠基期在训练孩子看卡片，其实它在训练你**不要开口**。孩子那一关通常两周就过了，大人那一关要练两个月。」
