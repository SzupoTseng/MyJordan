# 第15章　阶段三　职业探索期：从「小帮手」到「有职称的人」

**对应时程：** 高职一年级
**主核心：** C1（新环境的情绪）＋ C3（角色转换）
**这一站要交出的东西：** 三种以上能操作的工具、三句能自动说出口的职场台词、一个他认同的职称

---

## 背景与痛点

高职一年级是四年里**环境变动最大**的一年。

新学校、新老师、新同学、新作息、新通勤路线。对一个依赖可预测性的孩子来说，这是一次全面性的地基松动——而它刚好发生在他好不容易把国三练稳之后。

家长最常在这一年遇到的两件事：

**第一，前三个月看起来全部退步。** 情绪回复时间拉长，检核卡不理，固着碎念变多。这通常不是能力退步，是**环境重载**。

**第二，他开始「太热心」。** 因为人缘好、乐于助人，他会跑去帮每一组、每一个人。而在一个特教班里，其他同学未必都能好好回应——有些孩子会推开他、拒绝他、甚至情绪反击。**这是他这一年最容易受伤的地方。**

职业探索期要做的，是**在环境变动中把角色立起来**：他不再只是「爱帮忙的同学」，他是有职称、有工作范围、有标准说法的人。

---

## 核心设计：三个步骤

| 步骤 | 做什么 | 对应核心 |
|------|--------|---------|
| **① 环境转换的压力管理** | 开学前回诊、老师交接、前三个月降低训练强度 | 地基 |
| **② 工具多元减敏** | 从一种工具扩到多种，创建操作耐受 | C2 + 动作 |
| **③ 角色化与社交脚本** | 给他一个职称与明确的工作边界，配上制式台词 | C3 + C1 |

## 实作

### 步骤①：环境转换的压力管理

```text
【开学前一个月】
  □ 回诊一次，并主动告知医师「即将转换学校环境」
  □ 准备一份给新学校的交接数据（第 34 章有范本），内容包含：
      · 医疗与紧急处置（发作型态、紧急联系、就医纪录）
      · 固着行为的引导方式（手势、计时器、代币）
      · 有效的教学方式（视觉卡、双层指令、覆诵）
      · 「他最擅长什么」（★ 一定要写这一段）
  □ 若可能，开学前带他实地走一次校园与通勤路线

【开学后前三个月：降强度，不加新项目】
  · 训练强度降到平常的 6–7 成
  · 不导入任何新工具、新教材、新规则
  · 维持原有的检核卡与计时器（★ 熟悉的工具在陌生环境中是定锚）
```

> ⚠️ **医疗免责**
> 环境压力、疲劳与睡眠不足是常见的发作诱发因子。若孩子在新环境出现**频繁眨眼、短暂失神、呼唤无反应、或任何疑似发作的表现**，请记录时间与情境并尽速回诊，由医师判断是否需要调整。任何用药调整都必须由医师决定，家长不可自行增减。

### 步骤②：工具多元减敏

高职的职业实作课会用到各种工具。而一个只用过抹布的孩子，第一次拿到喷雾瓶、刮刀、标签机时，可能会直接拒绝——**不是不会，是新的东西让他不安。**

```text
【居家工具减敏清单】（每两周引入一种，不要一次全上）

  □ 不同材质的抹布（棉、纤维、菜瓜布）→ 擦不同的东西
  □ 喷雾瓶 → 练「压三下」的定量控制
  □ 刮玻璃器 → 练「由上往下、不重叠」的路径
  □ 平板拖把 → 练「沿着磁砖线推」的直线控制
  □ 标签机 / 贴纸 → 练「贴正、贴在同一位置」
  □ 剪刀 → 练沿线剪、剪直线（见第 27 章：为什么考剪刀）
  □ 夹链袋 / 封口 → 练「装、压、封」的三步骤
  □ 按压计数器 → 练计数与完工回报

【每一种工具的引入流程】
  1. 大人先示范一次（不解说，只做）
  2. 用固着外壳给它一个名字：
     「火车进站了，维修长要用这条蓝色抹布擦车窗。」
  3. 让他做，允许做不好
  4. 完成后具体称赞：「你有沿着线推，没有歪掉。」
```

**目标不是熟练，是不排斥。** 这一阶段的检核标准是「能操作三种以上不同工具，且单一工具能专注操作 15–20 分钟」，不是「做得多好」。

### 步骤③：角色化与社交脚本（本阶段的主角）

**给他一个职称。**

这件事听起来像游戏，但它在这个阶段的效果非常明确：**职称会把「被要求」转换成「扮演」，而扮演的抗拒成本远低于服从。**

```text
【职称设计三原则】
  1. 从固着兴趣里取材（维修长、站长、安全检查员、清洁组长）
  2. 有明确的工作范围（★ 这是保护他的关键）
  3. 在家与学校用同一个职称

【工作边界：这一段是为了保护他】
  明确告诉他：
    「你今天是 A 组的清点长，你只要看好 A 组的工具。
     B 组有 B 老师会帮忙，你不用过去。」

  → 用物理边界（哪一组、哪一张桌子、哪一个篮子）
    而不是抽象规则（「不要太鸡婆」）。
  → 这能防止他因为过度热心而被同侪拒绝，
    进而引发他最难处理的那种挫折。
```

**三句职场台词（练到不用想）：**

```text
① 卡住时：「请老师教我，谢谢。」
② 太累时：「我太累了，我想休息一下。」
③ 完成时：「报告老师，我做好了，请检查。」

【练法】
  每天在实作或家事中，故意制造 1 次「卡住」的情境
  （给一个他不会的步骤、或把工具收起来），
  引导他使用台词，成功就大力称赞。

【高端：冲突时的台词】
  同组的人做错、或自己被打断时：
    「没关系，我们重新做。」
    「好，我们现在先工作。」
  → 用制式语言覆盖掉情绪反应。
    自闭特质的孩子不擅长即兴社交，但**非常擅长运行剧本**。
```

> 🔍 **为什么「剧本」对他有效，而「道理」没效**
> 即兴社交需要即时判读对方的情绪、推测意图、选择合适的回应——那是他最弱的一组能力。
> 而运行固定脚本用的是进程性记忆，那是他相对强的一组。
> **把社交变成 SOP，不是降低标准，是换一条他走得通的路。**

## 每周五的三个观察指针

```text
① 新环境的生气频率
   每周因固着被中断或人际挫折而生气的次数
   目标：开学三个月内稳定在每周 ≤ 2 次，且无摔东西／大喊

② 工具操作
   能正确握持并独立完成的工具种类数
   目标：≥ 3 种；单一工具专注 ≥ 15 分钟

③ 岗位稳定度
   不需旁人叮嘱，能待在工作岗位上的持续时间
   目标：≥ 20 分钟
```

## 现场踩雷

**踩雷一：开学就加强训练。**
新环境本身就是高负荷。前三个月加强，等于在他最脆弱的时候加压。**降强度，让他先活下来。**

**踩雷二：把前三个月的退步当成能力退步。**
先查地基、先看环境，再谈能力。若同时出现**技能倒退**（原本会的不见了），那是医疗事件，见第 3 章红旗。

**踩雷三：不设工作边界。**
「他热心是好事啊」——热心加上没有边界，等于一年里反复被拒绝。**边界是保护，不是限制。**

**踩雷四：职称只有家里在用。**
学校不知道、老师没配合，角色就立不起来。**开学交接数据里要写明这一项。**

**踩雷五：工具一次上太多。**
两周一种。八种工具就是四个月，刚好一个学期。

**踩雷六：台词只在家里练。**
一定要有学校版本。第 34 章的备忘录里包含这三句话，可以直接交给老师。

## 离站标准（DoD）

| 项目 | 标准 |
|------|------|
| 环境适应 | 开学三个月后，每周生气次数 ≤ 2 次，且无失控行为 |
| 工具 | 能正确操作 ≥ 3 种职场基本工具，单一工具专注 ≥ 15 分钟 |
| 岗位 | 不需叮嘱，稳定待在岗位 ≥ 20 分钟 |
| 台词 | 三句职场台词中至少 2 句能在无提示下自发使用，每周 ≥ 3 次 |
| 角色 | 家庭与学校使用同一职称；工作边界明确且孩子能说出「我负责哪一组」 |
| 协作 | 能与同侪共同完成一项 20 分钟的实作，过程中情绪不失控 |
| 资源 | 本学年已参访至少 1 家机构（小作所／庇护工场／日照） |
| 地基 | 开学前已回诊并交接；睡眠在新作息下重新稳定 |

> 💡 君之一席话
> 「他不是变得不听话，他是**同时要处理新学校、新同学、新路线，和一个没有人帮他翻译的世界**。这一年你要给他的不是更多训练，是一个职称、一张桌子、和一句『这一组是你的』。」
