# 第16章　阶段四　职场耐受期：吵、久、累的时候，还做得下去吗

**对应时程：** 高职二年级
**主核心：** C1 神经控制力（抗干扰与疲劳管理）
**这一站要交出的东西：** 一段吵闹中仍然不停的手、一句累到极点时说得出口的求助

---

## 背景与痛点

到了高职二年级，多数家长会发现一件事：**孩子在家里表现很好，一到外面就不行。**

在家里，安静、熟悉、只有他和妈妈。他可以折衣服折三十分钟。

到了实作教室，二十个同学、机器声、老师的广播、隔壁组在吵架。他做了五分钟就擡头、发呆、开始讲火车。

这不是他懒，是**专注力的成立条件不同**。在无干扰环境中创建的专注，不会自动类化到有干扰的环境——而他未来要去的地方（小作所、庇护工场、任何一种职场）**全部都是有干扰的环境**。

还有第二件事：**疲劳。**

高二的实作课会拉长到连续一到两小时。在疲劳的后半段，孩子的抑制能力会掉下来——本来忍得住的，现在忍不住。而这时候如果没有替代方案，唯一的输出就是发脾气。

**职场耐受期要练的，就是这两件事：吵的时候不停，累的时候会说。**

---

## 核心设计：三个步骤

| 步骤 | 做什么 | 对应核心 |
|------|--------|---------|
| **① 产量概念** | 用计数器创建「做多少」的具体感 | C2 + C3 |
| **② 抗干扰训练** | 在受控的干扰下维持工作 | C1 |
| **③ 疲劳时的求助** | 把「累到发脾气」换成「累了会说」 | C1 |

## 实作

### 步骤①：产量概念与计数器

在此之前，任务的完成标准是「做完」。这一阶段开始，加入「做了多少」。

```text
【火车出厂计数器】
  一个实体按压计数器（文具店的计数器即可），粘贴他的主题贴纸。

  规则：
    · 每完成 N 个单位（10 个包装、5 张桌子、20 件衣服），
      他自己按一下计数器（★ 一定要自己按）
    · 累积到当日目标数量 → 换取休息时间或一张奖励贴纸
    · 目标数量由「他昨天实际做到的量」决定，不要凭空设置

【为什么要有实体计数器】
  · 可视化：抽象的「产量」变成看得见的数字
  · 触觉回馈：「按下去」那一声，本身就是完工的信号
  · 自主性：数字是他自己按出来的，不是大人记的
```

**家庭产线：每天 30–40 分钟**

```text
【居家代工的实作内容（挑一种，做稳再换）】
  · 全家衣物分类折叠（依人／依类别放进不同抽屉）
  · 采买回来的干货分装（固定数量装袋、封口）
  · 资源回收分类
  · 擦拭全家门把、开关、桌面（依固定路线）

【流程】
  1. 计时器设 30–40 分钟（比 S1 的时长加倍）
  2. 他站在或坐在固定的工作台前，连续作业
  3. 大人在旁计时、计量，但不聊天、不指导
  4. 时间到 → 品质自检 → 按计数器 → 工具归位 → 「下班」
```

### 步骤②：抗干扰训练（本阶段的主角）

完整原则在第 8 章。这里是高二版本的强度：

```text
【每周 2–3 次，每次 20–30 分钟】

  1. 进行重复性作业，计时器设 25 分钟
  2. 在第 10 分钟与第 20 分钟各制造一次干扰：
       · 播放他喜欢的火车音效或音乐
       · 旁边有人大声讲话
       · 忽然把某个工具拿走
       · 忽然说「这个先别做，改做另一个」
  3. 目标行为（择一即可）：
       · 不转头、手不停，持续 2–3 分钟
       · 或启动定格站姿 + 台词：「我现在要先把工作做完。」
  4. 成功 → 具体称赞
     失败 → 降低干扰强度，不责备

【禁止事项（再说一次）】
  ✗ 疲累、生病、情绪不佳的日子不做
  ✗ 一次练习不超过 2 次干扰
  ✗ 成功后不再加码
  → 目的是创建耐受，不是制造挫折。
```

### 步骤③：疲劳时的求助（这一节最重要）

**在庇护工场与小作所的现场，决定去留的往往不是产量，是「累的时候会怎样」。**

一个累了会说「我想休息」的人，主管可以安排；一个累了就僵住、跺脚、或直接离开岗位的人，主管会判定为风险。

```text
【疲劳求助的三步骤动作】（与第 8 章的定格站姿同一套）
  1. 双手在肚脐前方交叠
  2. 深吸一口气
  3. 说：「老师，我太累了，我想喝水休息。」

【怎么练：刻意制造疲劳点】
  · 在他工作到第 25–30 分钟（明显开始分心）时，
    大人主动提示一次：「你累了吗？累了要说什么？」
  · 他说出台词 → 立刻准许休息（★ 一定要真的准）
  · 重复两周后，改成不提示，等他自己说
  · 他自己说出来的第一次，要给非常明确的称赞：
    「你自己说你累了，很棒。休息五分钟。」

【★ 最关键的一条原则】
  他说了「我想休息」，就一定要让他休息。
  如果你回「再做十个就好」——这句台词就死了。
  下一次他不会说，他会直接发脾气。
```

### 疲劳管理：高墙式作息

高二的训练强度是四年里最高的。相对地，**放松也必须是刻意安排的**。

```text
【高墙式作息】
  · 放学回家后（例如 17:00 之后），不再进行任何学习或训练
  · 晚餐后进入放松模式：洗澡、听音乐、完全自由的火车时间
  · 就寝时间固定，睡眠不足的隔天，训练强度自动降半

【为什么要立这道墙】
  疲劳与睡眠不足是常见的发作诱发因子；而长期的过度训练，
  换来的通常不是进步，是抗拒与退步。
  这一站练的是耐受，不是耗竭——两者只差一线。
```

> ⚠️ **医疗免责**
> 若在高强度活动期间出现任何疑似发作的表现（短暂失神、抽动、意识改变）、异常的手部颤抖、或明显的白天嗜睡，**请记录并尽速回诊**。体能负荷与癫痫的关系、饮水量建议、以及任何用药调整，都应由主治医师评估。

## 每周五的三个观察指针

```text
① 抗干扰持续时间
   有噪音干扰下，手中工作不停顿的最长分钟数
   目标：≥ 25 分钟

② 产量与良率
   40 分钟作业期内的合格率（有没有因疲劳而后段品质下滑）
   目标：≥ 90%

③ 疲劳时的情绪控制
   工作到最后 10 分钟时被打断或换任务，能否接受调度
   目标：面露疲态但能配合，或主动使用求助台词
```

## 现场踩雷

**踩雷一：把抗干扰练成整人。**
干扰训练的目的是耐受，不是测试底线。**连续干扰、加码干扰、在他状态差时干扰——都会让「忍耐」与「被欺负」产生链接。**

**踩雷二：他说累，你说再一下。**
这是本章唯一一条「一次就毁掉」的规则。

**踩雷三：只练产量，不练良率。**
机构评估同时看两者，而且**良率通常更重要**——做得慢可以安排，做坏了要重工。

**踩雷四：晚上还在加课。**
高墙式作息不是偷懒，是保护。

**踩雷五：把疲劳的表现当成态度问题。**
后半段变差是生理现象。正确处理是缩短单次时长、增加休息点，而不是要求他「再撑一下」。

**踩雷六：忘了 S3 的台词。**
求助台词是 S3 创建、S4 大量使用的。如果 S3 没练起来，这一站要先回头补。

## 离站标准（DoD）

| 项目 | 标准 |
|------|------|
| 抗干扰 | 在干扰环境下持续工作 ≥ 25 分钟，连续两周稳定 |
| 产量与良率 | 40 分钟作业期，合格率 ≥ 90%，且后段无明显下滑 |
| 求助台词 | **能在无提示下**于疲劳时说出求助句，每周 ≥ 2 次 |
| 疲劳调度 | 工作末段被打断或换任务时，能接受调度，无失控 |
| 计数器 | 产量目标由孩子自己按计数器达成，连续四周 |
| 作息 | 高墙式作息落实 ≥ 80% 的日子；睡眠时数稳定 |
| 资源 | 已完成第 2 家机构参访；知道各家的收案条件 |
