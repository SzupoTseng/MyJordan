# 第17章　阶段五　实习期：陌生的地方、陌生的主管、和一张自己画的地图

**对应时程：** 高职三年级上学期
**主核心：** C2（陌生人的复合指令）＋ C1（环境重载）
**这一站要交出的东西：** 一条自己走得完的通勤路线、一张口袋里的地图、一份职评的好印象

---

## 背景与痛点

前四站都在**熟人环境**里完成：妈妈、特教老师、同班同学。

实习期第一次把他放到**没有人认识他**的地方。现场主管不知道他的固着、不知道他的手势、不知道他为什么忽然停下来。那里的噪音更大、规则更陌生、而且没有人会替他翻译。

同时，这一学期还有一件会影响往后十年的事：**职业重建评估。**

各县市劳工主管机关的职业重建个案管理师会入校评估，这份评估与后续的媒合，很大程度决定了毕业后他能去哪里。而评估看的是**真实现场的表现**，不是家长的说法。

**实习期的核心，是把「在熟人面前做得到」变成「在陌生人面前也做得到」。**

---

## 核心设计：三个步骤

| 步骤 | 做什么 | 对应核心 |
|------|--------|---------|
| **① 陌生环境的空间内化** | 把新场所画成地图，降低迷航焦虑 | C1 |

## 实作

### 步骤①：一张口袋里的地图

陌生空间对这类孩子造成的焦虑，经常被大人低估。**他不是怕工作，他是不知道厕所在哪里。**

```text
【实习第一天要做的第一件事】
  陪他把实习场所的关键点画成一张小地图（A6，护贝，放口袋）：

    我的工作桌 → 洗手间 → 饮水机 → 休息区 → 主管在哪里

  · 用简单的线和方框，不需要精确
  · 每个点贴一张实际拍的照片更好
  · 明确告诉他：「不知道怎么办的时候，把它拿出来看。」

【第二张卡：紧急卡】
  正面：我的名字、实习单位、联系人电话
  背面：三句话
        「请老师教我，谢谢。」
        「我太累了，我想休息一下。」
        「我做好了，请检查。」
  → 他自己看得懂，别人也看得懂。
```

### 步骤②：通勤独立性（固着功能化的最高应用）

这一步是整本书里，**固着兴趣兑现得最彻底的一次**：那个讲了十几年火车的孩子，现在要真的搭火车去上班。

```text
【通勤训练的五个梯度】（每一梯至少 4 次成功再往下走）

  梯度 1  全程陪同，大人操作
  梯度 2  全程陪同，他操作（刷卡、看跑马灯、上下车）
  梯度 3  大人同车厢但保持距离，不介入
  梯度 4  大人在后方暗中观察（不同车厢／不同位置）
  梯度 5  独立通勤，大人在终点等（或以电话确认）

★ 梯度 5 是否运行，取决于路线的安全条件、孩子的判断力、
  以及当地环境。**这不是必须达成的目标**——很多成年身障者
  终生使用陪同或接送，那完全没有问题。
  能做到就是加分，做不到就用第 18 章的替代方案。

【通勤中的规则（★ 这一条每次都要重申）】
  「在车上，火车只能用眼睛看，不能大声说。」
  兴奋到失控时 → 手势，不用嘴巴。
  回到家再给他一段完整的火车时间作为出口。
```

> ⚠️ **安全高于一切**
> 通勤训练的每一个梯度，都必须以**安全**为前提评估：路线是否需要跨越危险路口、车站是否有无障碍与服务人员、孩子在突发状况（误点、改线、有人搭讪）下的反应如何。
> 若有任何疑虑，**停在较低的梯度就好**。独立通勤是选项，不是必须。

**突发状况的减敏演练：**

```text
【惊喜减敏】（每两周一次，在安全情境下）
  出发前忽然改变计划：
    「今天火车坏掉了，我们改搭公车。」
  引导他看路线图，并念出台词：
    「没关系，改搭公车也可以到。」

  → 目的是让「计划改变」变成一件练习过的事，
    而不是第一次发生就在实习现场。
```

### 步骤③：职场脚本与评估准备

```text
【陌生主管的四步应对】（把 S3 的台词升级为完整流程）

  1. 听指令：眼神看着对方，不要先动
  2. 覆诵：点头 + 大声覆诵核心名词
       主管：「把这箱货拿去 A 货架上架，然后把空箱拿去后面回收。」
       他：  「好，A 货架上架，空箱回收。」
  3. 运行：依序完成
  4. 回报：「报告，我做好了，请检查。」

★ 第 2 步是整套流程的关键。它做两件事：
  · 对他自己：把听觉输入转成语音输出，记得住
  · 对评估者：展现「听得懂、会确认」的工作人格
```

**实习期间的固着管理（比平常更严）：**

```text
· 工作时间内，主动提起火车／游乐园的次数目标为零
· 休息时间可以讲，但仍在时间框内
· 现场想讲时 → 使用第 8 章的手势，或自我提示台词：
  「我现在要先工作，下班再说。」

★ 这不是压抑，是场合概念。回家后的火车时间必须加长，
  作为一整天克制的出口——**克制必须有出口，否则会在周末爆炸。**
```

### 周末减压：这一站的隐藏必修

实习期最常见的问题不在平日，在周末。

孩子在周一到周五为了「勉强控制」耗尽了所有前额叶能量，到了周六会出现极度疲惫、易怒、疯狂碎念——家长常误以为是退步。

```text
【周末减压原则】
  · 周末两天不安排任何训练、不谈实习
  · 完全接纳他的碎念与疲惫（★ 这两天不运行代币制）
  · 可安排一次真正的火车小旅行，作为一周辛苦的兑现
  · 周日晚上确保充足睡眠，让下周的地基重新填满
```

## 每周的三个观察指针

```text
① 陌生环境指令理解率
   现场主管交办的 2–3 步复合指令，能否不经翻译正确运行
   目标：≥ 80%

② 工作时段的固着抑制
   工作时间内主动提起固着话题的次数
   目标：零（休息时间不计）

③ 交通与安全规范
   黄线、闸门、红绿灯的遵守
   目标：100%，且无任何冲动穿越或脱序
```

## 现场踩雷

**踩雷一：实习前没有交接。**
现场主管不知道他的状况，就无法提供合适的支持，也可能误读他的行为。**交接数据与紧急处置说明，必须在第一天之前送到现场。**

**踩雷二：把独立通勤当成必达目标。**
安全永远优先。**做不到就用接送或陪同**——这不影响机构收案，也不代表训练失败。

**踩雷三：周末继续加训。**
这是实习期最常见的翻车原因。**周末的功能是修复，不是加码。**

**踩雷四：只练工作，没练「不会的时候怎么办」。**
现场一定会遇到没教过的状况。**「请教我」这句话的价值，在这一站达到最高。**

**踩雷五：职评当天才第一次见到职管员。**
若有机会，在评估前先让孩子见过对方、或至少熟悉评估的场地与流程。**陌生度降低，表现就会接近真实水准。**

**踩雷六：家长在评估时抢着回答。**
评估的是孩子，不是家长。**该说的写在书面数据里，现场让孩子自己表现。**

## 离站标准（DoD）

| 项目 | 标准 |
|------|------|
| 空间内化 | 实习场所地图完成并实际使用；能自行找到厕所、饮水机、主管 |
| 陌生指令 | 陌生主管的 2–3 步指令运行成功率 ≥ 80% |
| 覆诵 | 面对陌生人交办时，能主动覆诵核心名词，达 ≥ 70% |
| 固着抑制 | 工作时段主动提起固着话题次数为零，连续两周 |
| 通勤 | 达到梯度 3 以上；或已确立可行的替代通勤方案 |
| 交通安全 | 100% 遵守安全规范，无安全事件 |
| 突发应变 | 至少完成 4 次惊喜减敏演练，能使用台词自我安抚 |
| 周末修复 | 周末减压原则落实；周一的状态未见持续恶化 |
| 制度 | 已完成职业重建评估相关流程；家长知道下一步的媒合方式 |
