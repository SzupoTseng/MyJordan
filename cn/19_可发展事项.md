# 第19章　可发展事项：达标之后，往上叠什么

## 背景与痛点

每一站都有离站标准。但离站标准是**及格线**，不是天花板。

有些孩子会在某一站表现得比预期好——三格检核卡两周就稳了，两步指令一个月就通了。这时候家长通常会做两件事之一：

**第一种：立刻冲下一站。** 结果是地基还没有真正扎实（只是在熟悉情境下达标），到了下一站全面崩盘。

**第二种：原地维持。** 「反正还没到下学期」，于是三个月都在做同一件已经会的事。孩子开始无聊、开始敷衍，而那个「本来可以再往上一层」的窗口就这样过去了。

这一章给第三种选择：**在同一站的深度上加码。**

不是往前跑，是往下扎。而扎的方式有一个共通原则：

> 🔍 **加值原则**
> **永远在他展现优势的时候，悄悄塞进下一个难度；永远把新难度包在他最爱的东西里。**
> 他在做他擅长的事、情绪最好的时候，是接受新挑战成本最低的时刻。而等到他卡住、挫折、生气的时候才加码，那叫加压，不叫加值。

---

## 核心设计：加值 vs 升阶

| | 升阶（往前开一站） | 加值（在原站往下扎） |
|---|---|---|
| 什么时候做 | 离站标准全部达成且稳定两周 | 部分项目提早达标，但整体还没过门 |
| 动的是什么 | 换一组核心与主题 | 同一组能力的**广度**与**稳定度** |
| 风险 | 地基不稳会全面崩盘 | 低（因为在熟悉的范围内） |
| 效果 | 进度 | **类化**——同一件事在更多场合都成立 |

**加值追求的是类化，而类化是这条路上最被低估的一件事。**

一个孩子在家里、在妈妈面前能做到的事，不代表他在学校、在陌生人面前做得到。而机构评估的、未来人生用得到的，全部是后者。

## 实作：六站的加值清单

### S1 奠基期的加值

```text
【加值 1】从「任务卡」扩到「全屋视觉系统」
  目前：只有小帮手任务用检核卡
  加值：把家中的每一段例行进程都做成视觉图卡

    浴室：  上完厕所 → 冲水 → 洗手 → 擦干
    出门前：带钥匙 → 带悠游卡 → 带水壶 → 穿鞋
    睡前：  洗澡 → 刷牙 → 换衣服 → 火车时间 → 关灯

  神经效益：把「听指令」换成「看图标」，可以把口语理解的
  负荷整段省下来，留给更需要它的地方（情绪与人际）。

【加值 2】固着时间的「限时高密度输出」
  目前：15 分钟火车时间，大人听他讲
  加值：在同样的 15 分钟里，要求结构
    「你今天要介绍哪三个？第一个是什么？第二个呢？」
  神经效益：把无目的碎念，练成有组织的语音输出。
  这是他唯一会主动大量产出语言的场合——不用可惜。
```

### S2 转化期的加值

```text
【加值 1】逆向语序（十六级的第 9 级）
  目前：「把碗拿到厨房，然后拿卫生纸。」（顺向）
  加值：「在拿抹布之前，先把本子交给老师。」（逆向）
  做法：先用两张图卡让他「按照要做的顺序」排一次，再运行。
  神经效益：需要先解码再重排，是语意处理的高端操作。

【加值 2】从「钱够不够」到「钱会变少」
  目前：能认面额、知道哪张够付
  加值：找零与余额（第 24、25 章）
    「火车票 150，你给我 200，我要找你多少？」
    先不要求心算，要求的是动作链：
      付大钞 → 等找零 → 拿到零钱 → 放进钱包
  神经效益：把数字接到「会变化的量」，这是理财概念的起点。
```

### S3 职业探索期的加值

```text
【加值 1】力道控制谱
  目前：能操作三种以上工具
  加值：同一种工具的不同力道与路径
    · 喷雾瓶：压 1 下 / 压 3 下（定量）
    · 抹布：  轻擦玻璃 / 用力刷污渍（分级）
    · 拖把：  沿磁砖线推直线 / 转角收边（路径）
    · 剪刀：  沿粗线剪 / 沿细线剪 / 剪曲线（精度）
  神经效益：手部精细动作与大脑运动皮质的双向刺激；
  而职评现场考的，恰恰是这种「控制得住」的能力（第 27 章）。

【加值 2】职场客套语的自动化
  目前：三句求助台词
  加值：迎宾与交接的固定脚本
    有人进教室 → ① 看人 ② 微笑 ③ 说「请进」
    交东西给人 → 双手递出 + 「请拿」
    接受指正   → 「好，我改。」
  神经效益：他不擅长即兴社交，但非常擅长运行脚本。
  脚本越多，他在人群里越安全。
```

### S4 职场耐受期的加值

```text
【加值 1】选择性注意的分级
  目前：有干扰时能持续工作 25 分钟
  加值：把干扰分级，逐级提高
    第 1 级  背景音乐
    第 2 级  他喜欢的声音（火车音效）★ 最难的一种
    第 3 级  有人在旁边对话
    第 4 级  有人直接跟他说话（他要能说「等一下」）
    第 5 级  任务被临时更换
  神经效益：真实职场的干扰是混合的。分级练过，现场才有底。

【加值 2】疲劳的自我侦测
  目前：被提示时会说「我太累了」
  加值：在还没被提示前，自己察觉并说出来
    做法：教他一个身体信号的自我检查
      「手会不会抖？眼睛会不会酸？想不想坐下？」
      三个有一个 → 举手说「我想休息一下」
  神经效益：从「别人发现他累了」到「他自己知道」，
  这是自我调节的最高一阶。
```

### S5 实习期的加值

```text
【加值 1】认知弹性（面对计划变更）
  目前：能完成既定流程
  加值：计划被打断时的替代路径
    做法：每两周一次「惊喜减敏」，并教他一句总结台词：
      「没关系，改成 ___ 也可以。」
  神经效益：计划变更是自闭特质最恐惧的一件事，
  也是职场最常发生的一件事。练过，就不会是灾难。

【加值 2】自己画地图
  目前：大人帮他画实习场所的地图
  加值：换他来画
    到一个新地方，让他自己找出四个点并画下来：
      我的位置 / 厕所 / 喝水 / 找谁
  神经效益：从「被给予结构」到「自己创建结构」，
  这是他未来换工作、换机构时最需要的一项能力。
```

### S6 转衔期的加值

```text
【加值 1】用科技载具接手提醒
  目前：靠家人叫他、靠墙上的月历
  加值：智能手表／手机的定时震动提醒
    07:30 起床 / 08:00 出门 / 12:00 午餐 / 17:00 下班
  神经效益：把「依赖家人口头叮咛」转移到「客观的设备」。
  这不只是效率问题——它让他看起来、也感觉起来像个
  自己在管理生活的成年人。

【加值 2】固着兴趣的同侪社交化
  目前：固着已被限时、被结构化
  加值：让它成为社交资产
    每周五带一张自己选的火车照片，在休息时间给同事看，
    并说：「这是我最喜欢的自强号，送给你（给你看）。」
  神经效益：把「自我封闭的固着」转成「双向的成人社交」。
  在一个他可能待十年、二十年的地方，好人缘是最好的保护网。
```

## 现场踩雷

**踩雷一：把加值当成升阶。**
加值不会让你提早离站。离站标准还是那些，一项都不能少。

**踩雷二：在他卡住的时候加值。**
加值要在他表现好、情绪好的时候塞。卡住时该做的是降阶，不是加码。

**踩雷三：一次加两项。**
每站的两项加值，建议相隔至少四周。

**踩雷四：加值变成「再多做一点」。**
加值是**换一个角度做同一件事**，不是延长时间。时长上限不变。

**踩雷五：只在家里加值。**
加值的目的是类化。**只在家做的加值，等于没做。**

## 效益与验收（DoD）

| 项目 | 验收标准 |
|------|---------|
| 加值有节奏 | 每站至多同时进行 1 项加值，间隔 ≥ 4 周 |
| 时机正确 | 加值都是在孩子状态好、部分项目已提早达标时导入 |
| 有类化 | 每项加值都至少在**两个场域**（家 + 学校／社区）实施过 |
| 未挤压时长 | 平日每天训练总时长仍在 45 分钟以内 |
| 有记录 | 加值项目写进活动标注卡（第 7 章），含 `stop_rule` |

> 💡 君之一席话
> 「加值不是把油门踩深，是把轮胎换宽。**同一段路，走得稳比走得快值钱**——因为四年后真正决定他去哪里的，不是他学过多少，是他在陌生人面前还剩下多少。」
