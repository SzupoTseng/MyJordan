# 第25章　M07　纪念品找零：付大钞、拿零钱、收好

**维度：** D2 金钱与等价交换
**对应核心：** C2（动作链）＋ C1（延宕满足）
**成人生活场景：** 买东西不会漏拿找零，不会在柜台前被占便宜

---

## 背景与痛点

在购物这件事上，认知落后的孩子脑中通常只有两条线：**递出钱**，和**拿到东西**。

中间那一步——**拿回找零**——经常整段消失。

而它消失的方式很典型：他右手接过商品的那一瞬间，大脑释放「任务完成」的信号，身体开始转身。找零还在店员手上，或者被放在柜台上，或者塞进口袋然后掉了。

一次五十元，一周两次，一年五千元。而更严重的是：**一个从不确认找零的人，在遇到不诚实的店家时，没有任何防线。**

M07 练的不是心算。它练的是一个**四步骤的动作链**：

```text
付钱 → 拿到东西 → 左手等零钱 → 放进钱包关好
                     ↑
              整条链里最容易断的一环
```

---

## 实作

### ① 教具与场景

```text
【道具】
  □ 一个他真的想要的东西（火车模型、玩偶、他喜欢的零食）
  □ 标价卡：「450 元」，字要大，贴在商品上
  □ 孩子的钱包里放 1 张 500 元
  □ 家长的「收银柜台」（一个盒子）里放 1 枚 50 元硬币

【为什么是 500 买 450】
  找零是「一枚 50 元硬币」——单一整数硬币。
  他不需要做任何扣减计算，只需要创建一个视觉图像的对应：
      付绿色的 500 → 拿回金色的 50
  等这个动作链固定之后，再谈数字。

【场景】
  家长在桌子一端摆商品，扮演「纪念品店店员」；
  孩子手拿钱包站在对面，扮演「结帐的客人」。
```

### ② 三部曲脚本（逐字）

```text
【第一步　标价辨识与付款】

  家长（双手拿着商品，微笑）：
    「欢迎光临！维修长今天工作辛苦了，想买这只老虎对不对？
     上面写着 450 元。」

  家长（伸手）：「请你打开钱包，拿一张 500 元付钱。」

  期望反应：主动打开钱包 → 抽出 500 元 → 递出


【第二步　双手防线】★ 本教材的核心，也是最难的一步

  家长接过 500 元。
  右手把商品递给孩子，**左手拿着 50 元硬币，但先不给**。

  ▸ 此时会发生什么：
    他右手接过商品的瞬间，准备转身。
    这不是不专心，是「任务完成」的信号被提早触发了。

  家长动作：
    左手把 50 元硬币伸到他**左手前方**，
    同时用身体与眼神温和地挡住他转身的动线。

  制约口诀（固定一句，一字不改）：
    「等一下，钱还没拿完。
     付五百，找五十。请左手拿亮晶晶的五十元。」

  期望反应：右手抱着商品，左手接过硬币

  ▸ 「左手」这个指定不是随便的：
    它让「拿商品」与「拿找零」变成两个分开的、
    看得见的动作，而不是混在一起的一团。


【第三步　硬币归位】

  家长（保持督导的眼神，不催）：
    「请把找回来的五十元，放进钱包里收好。」

  期望反应：右手夹着商品，左手（或双手配合）
            把硬币放进钱包 → 拉上拉链

  增强：「太棒了！东西买到了，五十元也收好了。
         维修长今天的金钱任务一百分。」
```

### ③ 量化检核

```text
【频率】每周 3 次（可利用点心时间仿真购物）

指针一　拿回零钱的「主动性」★ 最重要
  定义：接过商品后，**不经口诀提示**，左手主动伸出来等零钱的次数

指针二　零钱收纳的「完整度」
  定义：拿到硬币后，是随手放桌上／塞口袋，
        还是能放回钱包并关好

【过关标准】
  连续两周，10 次结帐中 ≥ 8 次：
    · 拿到商品的同时，左手自主等待零钱
    · 完成收纳与拉链动作
  达标即代表「购物三部曲」的动作链已经固化。
```

### ④ 情绪重载的处理：等待找零时的焦虑

**这一组会出现一个 M04、M05 都不会出现的状况：他会因为「等不到零钱」而生气。**

因为对他来说，交易的秩序被打断了。当店员（家长）动作慢、或故意把硬币拿在手上多停两秒，他的焦虑会迅速上升——面露不悦、原地跺脚、伸手去抢。

```text
【错误做法】
  「不可以生气！」
  → 他的生气来自「秩序被延迟」，那是固着特质的展现，
    不是无理取闹。用禁止的方式处理，只会升级。

【正确做法：把等待合理化】
  家长把 50 元推到他面前，同时做出「五指并拢向前」的手势，
  冷静地说：

    「维修长，收银机正在数钱。
     请你深呼吸，手放好，老板现在就把五十元交给你。」

  → 把「大人动作慢」解释成「机器正在运作」。
    他对「机械式的规律运作」包容度极高——
    他可以接受机器需要时间，但不容易接受人的随意。

  → 而这几秒钟的等待，本身就是一次
    **延宕满足**的前额叶练习。
```

### ⑤ 高端与真实情境

```text
【高端 A：找零的组合】（S3 以后）
  付 500 买 380 → 找 120（一张 100 + 一个 20）
  → 从单一硬币进到多枚组合。动作链不变，只是内容变复杂。

【高端 B：确认找零】（S4 以后，这是防卫能力的关键一步）
  教他在拿到找零后，做一个固定动作：
    看一眼硬币 → 说「谢谢」→ 收进钱包
  ★ 不要求他验算金额，只要求他「有看」。
    一个会低头看一眼的人，和一个从不看的人，
    在店家眼中是完全不同的两种客人。

【真实情境（★ 每四次桌上练习，一次这个）】
  带他去他熟悉的商店，买一样 200 元以内的东西，
  刻意用大钞付款，让找零一定会发生。
  流程全部由他做，大人只在他要转身时，
  用手势提醒（不用嘴巴）。
```

## 现场踩雷

**踩雷一：家长顺手帮他收零钱。**
「他手上拿着东西不方便，我帮他收」——这一收，整条链就断了。**宁可站着等他慢慢弄。**

**踩雷二：用一大堆零钱当找零。**
一开始就找 137 元（一张 100 + 一个 20 + 一个 10 + 一个 5 + 两个 1），他会直接放弃。**单一硬币起步。**

**踩雷三：故意测试他，把硬币拿太久。**
测试延宕满足是有价值的，但**不要在他已经接近临界的时候测**。而且测试要有上限——三到五秒，不是三十秒。

**踩雷四：把「不会算找零多少」当成失败。**
他不需要会算。**他需要会「等、拿、收」。** 计算是加分题，不是及格线。

**踩雷五：在真实柜台前替他说话。**
「他要买这个，这是五百」——你讲完了，他就没有练到。**让他自己递钱，你站在后面。**

**踩雷六：买的东西他不想要。**
这一组教材的动机全部来自那个商品。**用他真的想要的东西**，哪怕只是一包饼干。

## 效益与验收（DoD）

| 项目 | 标准 |
|------|------|
| 动作链 | 「付钱 → 拿商品 → 左手等零钱 → 收进钱包」四步完整，≥ 80% |
| 主动性 | 不经提示主动等零钱，10 次中 ≥ 8 次 |
| 收纳 | 找零收进钱包并关好，≥ 80% |
| 延宕满足 | 等待找零 3–5 秒时，能在提示下保持手放好，不抢不跺脚 |
| 真实情境 | 在真实商店完成含找零的结帐 ≥ 3 次，全程由他操作 |
| 确认动作 | （高端）拿到找零会低头看一眼并说谢谢 |

> 💡 君之一席话
> 「他不必算得出五百减四百五十等于多少。他只要记得**手还没收回来，交易就还没结束**——这一件事，会替他挡掉往后几十年里，那些不老实的柜台。」
