# 第34章　说服体系：IEP、鉴辅会，与把资源要到手

![会议前的三份文档与提案优先序](diagrams/d34_meeting.svg)

## 背景与痛点

会议室里坐着七个人：特教老师、导师、行政、辅导、治疗师、家长，有时还有校外委员。时间四十分钟，要谈的事有十件。

而家长坐在那里，带着三个劣势：

**信息劣势。** 别人讲的是安置类型、服务时数、鉴定基准、转衔通报；而你只知道你的孩子。

**时间劣势。** 你有很多话想说，但轮到你的时候只剩五分钟，而且前面已经有人讲了三十分钟的行政流程。

**情绪劣势。** 谈的是你的孩子。任何一句「他这方面比较弱」都会刺到你，而你一旦情绪上来，接下来的话就没有人听得进去。

这一章要做的，是把这三个劣势逐一补上。核心只有一句话：

> 💡 **会议桌上唯一有效的语言，是「可评量的目标」与「具体的支持需求」。**
> 「请老师多关照」不会变成任何一项服务；
> 「他需要每天一张三格视觉检核表，并在交办后由老师要求覆诵」会。

## 核心设计

### 一、三种会议，三种目标

| 会议 | 谁召开 | 你要拿到什么 |
|------|--------|-------------|
| **IEP 会议**（每学期） | 学校特教团队 | 写进纪录的**可评量目标** + 具体支持策略 |
| **鉴定与安置**（升学前） | 县市鉴辅会 | 适合的安置类型与**支持等级** |
| **转衔会议**（毕业前） | 学校 + 校外单位 | 衔接的**单位、时程与交接内容** |

三者的共同点：**纪录比口头承诺重要。** 会议上讲得再好，没有写进纪录的，换一个老师就消失了。

> ⚠️ **医疗免责**
> 会议中涉及诊断、用药与医疗处置的叙述，**应以医师开立的诊断证明与病历摘要为准**。家长可以引用医师的用语与书面数据，但不应自行下诊断结论、描述药物疗效或承诺医疗效果。

### 二、会议前要准备的三份文档

**文档一：一页摘要（给所有人）**

```text
【一页摘要的六个区块】

  ① 现况（三句话）
     自理：可独立完成 ___、___、___
     沟通：可理解 ___ 步骤指令；表达以 ___ 为主
     情绪：___ 情况下会生气，目前可在 ___ 提示下自我调节

  ② 医疗（三行，且以医师书面为准）
     诊断 / 目前追踪科别 / 需要学校知道的紧急处置

  ③ 这学期的三个目标（★ 可评量，见下一节）

  ④ 需要学校提供的支持（★ 具体到可以运行）

  ⑤ 家庭端正在做什么（让对方知道你不是只在要求）

  ⑥ 联系方式与回报方式（希望多久收到一次回馈、用什么形式）
```

**文档二：能力证据**（第 6 章开始累积的文件夹）

三到五张照片或短视频：他在做家事、使用检核卡、完成代工、在超商结帐。**证据在会议桌上的说服力，远超过任何形容词。**

**文档三：给老师的备忘录**（见下方完整范本）

### 三、可评量目标怎么写

这是本章最实用的技能。第 20 章的四要件（行为、数量、时间窗口、场域）直接用在这里。

| ✗ 常见写法 | ✓ 可评量写法 |
|-----------|-------------|
| 提升专注力 | 在班级实作课中，能持续在工作岗位操作 **20 分钟**，中途不需口头提醒，达成率 **70%** |
| 加强语言表达 | 能在卡住时使用「请老师教我」求助，**每周 ≥ 3 次**，无需提示 |
| 改善情绪 | 固着话题被中断时，能在 **2 分钟内**配合下一活动，**连续两周**达成率 70% |
| 培养独立性 | 依三格视觉检核表**连续完成 2 项**班务，中途无额外口头提醒，达成率 70% |
| 增进人际 | 每周 **1 次**在下课时间以固定脚本与同侪分享（「这是我最喜欢的 ___，给你看」） |

**写成这样有三个好处：** 老师知道要做什么、期末可以验收、而且它本身就是你的训练计划——**家庭与学校做的是同一件事。**

## 实作

### 一、给老师的亲师沟通备忘录（完整范本）

开学第一周传给老师，或在 IEP 会议上递出纸本。**方括号请自行替换。**

```text
老师您好：

我是 【孩子姓名】 的家长。非常感谢老师与学校过去的照顾，
让他学会了良好的生活自理，还能在班上当老师的小帮手、
拥有好人缘。这对我们家长来说是很大的安慰。

以下提供孩子的医疗状况、行为引导方式，以及本学期的学习期望，
供老师教学与 IEP 参考。

────────────────────────────────
一、医疗与安全（重要）

  · 诊断与用药：【依医师诊断证明填写】
    目前于 【科别】 规则追踪，状况稳定。
  · 若在校出现 【失神／异常疲倦／抽搐等，依医师说明填写】，
    请第一时间联系家长：【电话】
  · 【若有】紧急处置说明与诊断证明影本，随函附上。
  · 请避免让他过度劳累；疲倦时允许他休息。

────────────────────────────────
二、他学得最好的方式（★ 最实用的一段）

  1. 视觉优于口语
     交办任务时，请给他一张三格视觉检核卡（我们家里在用同一套），
     让他自己打勾。相较于口头交代，他的独立完成率明显较高。

  2. 交办后请他覆诵
     说完任务后加一句「你说一次」，他能覆诵关键名词就代表有记住。
     这一步能大幅降低他做到一半忘记的情况。

  3. 卡住时请等 5–10 秒
     他需要一点时间提取。若立刻再说一次，他会改成等待提醒，
     反而更慢。等一下不行的话，用手势指方向通常就够了。

  4. 一次一到两件事
     他目前稳定的是 【一／两】 步骤指令。三步骤仍在练习中。

────────────────────────────────
三、固着行为的引导（他喜欢 【火车／游乐园】）

  · 我们在家使用「聊天券」：一天 3 张，一张 5 分钟，
    交出券才能聊。若学校方便，同一套做法会更一致。
  · 非约定时间他提起时，建议温和但固定地说：
    「现在不是 ___ 时间，请把券收好。」
    （同一句话、每次一样，他比较容易接受）
  · 他碎念时，请尽量不要进入口语争辩——用手势（五指并拢向前）
    并指向检核表，通常两分钟内可以收回。
  · 他焦虑或不安时，这个主题反而是最好的安抚工具。

────────────────────────────────
四、他的三句话（请告诉同学与其他老师）

  「请老师教我，谢谢。」＝ 他卡住了
  「我太累了，我想休息一下。」＝ 请让他休息（他说了通常是真的累）
  「报告老师，我做好了，请检查。」＝ 他完成了

────────────────────────────────
五、本学期的期望（可评量的三项）

  1. 【依上一节的写法填写】
  2. 【…】
  3. 【…】

────────────────────────────────
六、家庭端正在做的事

  · 每日 【15】 分钟功能性数学（火车票价、金钱辨识）
  · 每日家事产线 【30】 分钟
  · 每周 【1】 次社区实地（车站／超商）

再次感谢老师的耐心。若有任何状况，请随时与我联系。

【家长姓名】 敬上
【联系电话】
```

### 二、提案的优先级

会议时间有限，你不可能全部要到。**先想清楚哪三项是必要的，其余列为「有的话很好」。**

```text
【第一优先：安全与医疗】（一定要争取）
  · 紧急处置流程与联系方式写进纪录
  · 疲倦时可以休息的明确授权
  · 校外教学、实作课的支持人力

【第二优先：可评量的目标】（一定要争取）
  · 三项目标写进 IEP
  · 检核方式与回报频率讲清楚

【第三优先：教学策略】（尽量争取）
  · 视觉检核卡的使用
  · 交办后覆诵
  · 固着行为的一致处理方式

【第四优先：加值项目】（有就好）
  · 特定的实作课安排
  · 额外的社区适应活动
  · 特定的座位或分组安排
```

### 三、被拒绝的时候

会遇到的。常见的三种情况与回应方式：

```text
【情况一】「我们人力不够。」
  → 不要争论人力，改问：
    「那在现有人力下，哪一项是做得到的？」
    → 把一个大要求拆成一个小要求，先拿到一项，
      并且**写进纪录**。下学期从这一项延伸。

【情况二】「其他孩子也需要，不能只针对他。」
  → 「这个方法对其他孩子可能也有用，
      需要的话我可以提供我们在家用的版本。」
    → 把「特殊待遇」转成「可共用的工具」。

【情况三】「他这方面就是比较弱，不用太勉强。」
  → 这句话最伤人，但它通常不是恶意，是经验判断。
    回应方式：拿出证据。
    「他在家里的纪录是这样（拿出照片／纪录），
      所以我想试试看在学校能不能也做到。
      如果一个学期后没有进展，我们再调整目标。」
    → 用「试一个学期」降低对方的承诺成本。

★ 通用原则：不要在会议上赢。
  你要的是往后几年的合作，不是这四十分钟的胜负。
```

## 现场踩雷

**踩雷一：带着情绪去开会。**
会议前十分钟，把要说的三件事写在纸上。**照着念，比临场发挥安全。**

**踩雷二：只讲困难，不讲他会什么。**
只讲困难的家长，会让孩子被安置到支持等级过高的组别。**优势与需求要一起讲。**

**踩雷三：要求太多。**
一次要十项，通常一项都拿不到。**三项，写进纪录。**

**踩雷四：口头承诺就满意。**
「我们会多注意他」——换一个老师就没了。**写进会议纪录。**

**踩雷五：把老师当对手。**
绝大多数特教老师是这条路上最理解你的人。**他们的限制通常是资源，不是意愿。**

**踩雷六：数据太厚。**
三十页的数据没有人看。**一页摘要 + 三张照片 + 一份备忘录，就够了。**

## 效益与验收（DoD）

| 项目 | 标准 |
|------|------|
| 一页摘要 | 已完成六区块，并在最近一次会议实际使用 |
| 可评量目标 | 三项目标皆含行为、数量、时间窗口、场域 |
| 已入纪录 | 至少 2 项目标与 1 项支持策略写进 IEP 或会议纪录 |
| 备忘录 | 已交给导师与特教老师，并口头说明过一次 |
| 能力证据 | 文件夹中有 ≥ 10 张照片／短片，涵盖 ≥ 3 种能力 |
| 回报机制 | 已约定回报频率与形式（联系簿、LINE、每月一次…） |
| 时程掌握 | 知道下一个关键时间点是什么、什么时候 |

> 💡 君之一席话
> 「你在那张桌子上唯一的优势，是**你比任何人都了解他**。但了解不会自动变成资源——**它要先被翻译成一句可以验收的话，才会变成写在纪录上的一行字。**」
