# 第47章　感官：看不见的那个维度

![感觉调节四象限、七种感觉系统，与内感受这一块拼图](diagrams/d47_sensory.svg)

## 背景与痛点

同一间实作教室，对你来说是「有点吵」，对他来说可能是「有人在耳边敲铁板」。

这一章要补的，是全书一直绕着走、却没有正面处理的一个维度：**他接收到的世界，和你接收到的不是同一个。**

它为什么重要，可以用前面章节的三个未解之处来说明：

- 第 16 章：他在家能专注三十分钟，在教室五分钟就撑不住——你以为是专注力，可能是**听觉负荷**。
- 第 35 章：功能是「感官」的行为，代币与处罚完全无效——但书中只说了「找替代」，没说怎么找。
- 第 5 章：婴儿期「不哭不闹」的感觉低反应，十六年后仍然存在——**他到现在还是不知道自己饿了、要上厕所、快生气了。**

第三点是这一章的核心，而它有一个名字，多数家长从来没听过：**内感受**。

> 💡 **先讲证据等级**
> 感觉调节的**描述性框架**（辨识一个人在哪些信道上过度反应或反应不足）在职能治疗与特教实务中被广泛使用，临床效用高。
> 但**以感觉统合为名的疗程**，其疗效研究结果并不一致——这一点第 33 章已经标注过。
> 本章的立场：**用它来理解与调整环境（证据较稳），不要把它当成治疗课程来投资（证据不足）。**

## 核心设计

### 一、七种感觉系统

前五种大家都知道，后两种才是关键。

| 系统 | 接收什么 | 失调时的样子 |
|------|---------|-------------|
| 视觉 | 光、动态、颜色 | 怕日光灯闪烁、盯着旋转物、在杂乱环境找不到东西 |
| 听觉 | 声音 | 摀耳朵、对特定声音极度反应、吵杂中无法听指令 |
| 触觉 | 碰触、质地 | 讨厌衣服标签、不喜欢被轻触、却喜欢用力拥抱 |
| 味嗅 | 味道、气味 | 极度挑食、对某些气味反应强烈 |
| **前庭** | 头部位置与移动 | 一直摇晃／转圈，或极度害怕脚离地、怕电梯 |
| **本体** | 肌肉与关节的位置 | 动作笨拙、力道控制差、喜欢推拉重物、撞人 |
| **内感受** | **身体内部信号** | **不知道自己饿、渴、想上厕所、累、生气** |

### 二、内感受：这本书一直在讲、却没有命名的那一块

把前面散落的线索接起来：

```text
第 5 章　婴儿期不哭闹、尿布湿了不吵
第 11 章　对便意的感觉迟钝，需要「定时排便制约」
第 16 章　累到极限才发脾气，因为不知道自己累了
第 39 章　情绪升级到第 ④ 阶段才被发现，因为他察觉不到自己在生气
第 44 章　情境 35（腹胀两个月没人知道）、情境 40（第一次说「我头痛」）

→ 全部都是同一件事：**内部信号传得慢、传得弱、或解读不出来。**
```

这解释了一个长年的困惑：**为什么他总是「突然」爆发？**

因为对他而言，那可能真的是突然的。一般人会经历「有点烦 → 越来越烦 → 快受不了 → 爆发」的渐进，而内感受弱的人可能直接从「还好」跳到「爆发」——中间那几格他读不到。

**这也意味着：第 16 章的「疲劳求助」与第 39 章的「早期前兆」，本质上是在教内感受。**

```text
【内感受训练：三个可以做的】

① 命名身体信号（把内在状态外显化）
   在他明显有生理状态时，替他说出来：
     「你的手在抖，你可能累了。」
     「你一直摸肚子，是不是想上厕所？」
   → 大人先做「翻译」，他才可能学会自己读。

② 身体检查三问（接第 19 章的疲劳自我侦测）
   固定在工作 25 分钟时问一次：
     「手会不会抖？眼睛会不会酸？想不想坐下？」
   → 三个有一个 → 举手说「我想休息一下」。

③ 情绪温度计（0–3 级，配图标）
   平静 / 有点烦 / 很烦 / 受不了
   在他平静时教，在第 ② 阶段用（第 39 章）。
   → 目标不是让他描述情绪，是让他**在爆发前指出一个数字**。
```

### 三、四象限：他是哪一种

同一个人可以在不同信道上落在不同象限——这是最常被误解的一点。

| | **反应不足** | **反应过度** |
|---|---|---|
| **被动（不主动调节）** | **低登录**：叫他没反应、痛不喊、脏了不知道 | **敏感**：容易被吵到、被碰到就跳起来、分心 |
| **主动（会去调节）** | **寻求**：一直动、撞、转圈、摸东西、大声 | **回避**：躲人群、摀耳朵、拒绝某些质地与场所 |

```text
【怎么用这张表】
  · 低登录 → 需要「加大信号」：更明确的提示、更强的对比、
    定时制约（不能等他自己感觉到）
  · 寻求   → 需要「合法出口」：规律的感官活动时段，
    而不是禁止（第 35 章的替代感官输入）
  · 敏感   → 需要「降低背景」：环境调整优先于训练
  · 回避   → 需要「可预测与控制感」：预告、给他一个离开的方式

★ 本书主线的个案在多数信道上偏「低登录」（第 5 章），
  但在听觉上可能偏敏感（第 42 章情境 16）。
  **两者并存是常态，不是矛盾。**
```

## 实作

### 一、感官剖析观察表（两周）

不需要专业工具，观察并勾选即可。**目的是找出「哪一个信道、哪一个方向」，不是分类他。**

```text
【视觉】
  □ 在明亮或闪烁的灯下不舒服　□ 喜欢盯着旋转／闪烁的东西
  □ 在杂乱的桌面找不到东西　　□ 对特定颜色或图案强烈偏好

【听觉】
  □ 对特定声音摀耳朵（吸尘器、烘手机、警报）
  □ 在吵杂环境听不懂指令　　　□ 自己会制造声音（哼、敲、学声音）

【触觉】
  □ 讨厌标签、某些布料、剪指甲、洗头
  □ 不喜欢被轻触，但喜欢用力抱　□ 喜欢摸特定质地

【味嗅】
  □ 食物种类极少　□ 拒绝整类质地（湿、糊、脆）
  □ 对气味反应强烈（厕所、油烟、香水）

【前庭】
  □ 一直摇晃、转圈、跑跳　□ 怕脚离地、怕电梯、怕溜滑梯
  □ 坐不住，需要一直动

【本体】
  □ 力道控制差（太用力／太轻）　□ 喜欢推拉重物、钻被子
  □ 动作笨拙、常撞到东西

【内感受】★ 最容易被忽略
  □ 不说饿、不说渴　　□ 不知道要上厕所，或忍到最后一刻
  □ 累到极限才爆发　　□ 痛不喊、生病不说
  □ 情绪像「突然」发生，没有渐进

→ 每一项勾选后，标注方向：不足（↓）或过度（↑）
```

### 二、环境适配清单（比训练更快见效）

**这一段是本章投报率最高的部分。** 环境调整不需要孩子改变任何事，而且当天就能做。

```text
【家】
  □ 固定的低刺激角落（他可以自己去的地方）
  □ 睡前降低照明与噪音
  □ 收纳可视化但不杂乱（开放层架反而更乱 → 用有盖收纳）
  □ 衣物：剪掉标签、选他能接受的材质（这不是宠，是降负荷）

【教室／机构】（写进 IEP 或交接手册）
  □ 座位远离噪音源（门、走廊、机器）
  □ 允许使用降噪耳罩或耳塞（需与老师讨论规则）
  □ 给一个「可以去冷静」的指定位置
  □ 工作区视觉单纯（一次只放当前任务的材料）
  □ 转换时段给预告（第 8 章）

【职场】
  □ 固定工位、固定路线
  □ 高噪音时段的替代任务
  □ 明确的休息时机（不是「累了再说」——他读不到，见内感受）

★ 这些调整不是特权，是**让他能工作的条件**。
  就像近视的人需要眼镜——没有人会说那是特殊待遇。
```

### 三、感官活动时段（给「寻求」型）

```text
【原则】
  · 规律安排，不是等他失控才用
  · 放在需要专注之前（例如：作业前 10 分钟的大动作活动）
  · 选他真的喜欢、且安全的形式

【常见的形式】
  本体觉（多数人接受度最高）：推墙、提重物、搬椅子、
      钻被子、按摩球、咀嚼有嚼劲的食物
  前庭：荡秋千、旋转（★ 有癫痫病史者，
      任何剧烈或长时间的前庭刺激应先问医师）
  触觉：捏黏土、豆子箱、深压（用被子包）

⚠️ 诚实标注：这一类安排在实务上被广泛使用，家长回馈常是正面的，
   但研究证据不一致。**可以做，不要当成主要投资，也不要付高价
   购买「疗程」**——多数形式在家就能做（第 33 章的同一立场）。
```

### 四、把感官接回前面的章节

| 前面的困难 | 感官视角的重新解读 | 该做的 |
|---|---|---|
| 教室待不住（第 42 章情境 16） | 听觉敏感 + 视觉杂乱 | 环境调整优先于抗干扰训练 |
| 电梯一直按按钮（第 43 章情境 27） | 寻求（视觉 + 触觉回馈） | 替代物（计数器） |
| 极度挑食 | 味嗅／触觉敏感 | 质地渐进、与喂食专业合作 |
| 累到爆发（第 16 章） | 内感受不足 | 定时检查 + 身体三问 |
| 便意迟钝（第 11 章） | 内感受不足 | 定时制约，不等感觉 |
| 「突然」爆发（第 39 章） | 内感受不足 | 前兆清单由**大人**创建，不靠他自述 |

**这张表的意思是：** 第 47 章不是添加一堆训练，而是替前面的困难**换一副眼镜**。有些原本要靠训练解决的，换上这副眼镜后会发现——调环境更快。

## 现场踩雷

**踩雷一：把感官需求当成问题行为处罚。**
摇晃、摸东西、哼声、撞——这些若是寻求行为，处罚只会压抑而不会消失，而且会增加焦虑。

**踩雷二：花大钱买感统疗程。**
证据不一致。**先做环境调整（免费、当天见效），再谈其他。**

**踩雷三：只看外显的五感，忽略内感受。**
内感受是这一章最重要的一格，也是最少被谈的一格——而它直接连着疲劳、疼痛、情绪、如厕。

**踩雷四：把环境调整当成宠溺。**
耳罩、座位、固定路线——这些是**工作条件**，不是特权。而且它们通常比训练更省力、更快见效。

**踩雷五：贴标签而不行动。**
「他是感觉寻求型」——然后呢？剖析的目的是**找出要调哪一格**，不是分类他。

**踩雷六：前庭活动不问医师。**
有癫痫病史者，剧烈或长时间的旋转、跳跃等活动应先确认。

## 效益与验收（DoD）

| 项目 | 验收标准 |
|------|---------|
| 剖析完成 | 七个系统的观察表完成，并标注不足／过度 |
| 环境已调整 | 家庭与学校（或机构）各至少完成 2 项环境调整 |
| 内感受已命名 | 每天至少 1 次替他说出身体信号（「你的手在抖，你可能累了」） |
| 身体三问 | 工作 25 分钟的定时检查已实施满 4 周 |
| 情绪温度计 | 0–3 级的图标已制作，且在平静时教过 ≥ 5 次 |
| 感官时段 | 若为寻求型，已安排规律的感官活动时段（而非危机时才用） |
| 未过度投资 | 没有购买高价疗程；优先做的是环境调整 |
| 已写进文档 | 环境需求已写进 IEP 或第 18 章的交接手册 |

> 💡 君之一席话
> 「他不是突然爆发的。**是他和你，读到的不是同一份信号**——你看到的是十分钟的渐进，他读到的只有最后那一秒。」
