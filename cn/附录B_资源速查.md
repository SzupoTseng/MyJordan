# 附录B　台湾资源与工具速查

> ⚠️ **这一页的使用方式**
> 台湾的身心障碍与特教服务，**制度名称、申请条件、评估工具与承办单位会随法规调整，且各县市不同**。这份速查给的是「有哪些方向、该问谁、用什么关键字查」，**不是最新的办法条文**。
> 每一项在实际申请前，都请向**学校转衔老师**或**户籍地社会局（处）身心障碍福利科**确认。

## 一、毕业后的四种主要去向

| | **社区日间作业设施（小作所）** | **庇护工场** | **日间照顾中心** | **支持性就业** |
|---|---|---|---|---|
| 本质 | 具作业活动的日间服务 | 具庇护性质的**就业场所** | 生活照顾为主的日间服务 | 一般职场 + 就业服务员支持 |
| 身分 | 学员 | **劳工**（签订劳动契约） | 服务用户 | 受雇者 |
| 劳健保 | 无（多依附家属或国民年金） | **有** | 无 | 有 |
| 收入 | 作业奖励金（金额有限） | 依产能核薪的薪资 | 无 | 薪资 |
| 每日压力 | 较低，活动多元 | 中至高，有产量与出货压力 | 低 | 视职场而定 |
| 费用 | 通常需负担部分费用（依规定可能有补助） | 不需缴费（是去上班） | 通常需负担部分费用 | 不需缴费 |
| 适合谁 | 能简单沟通、自理佳、情绪大致可控 | 具一定作业能力与产能耐受 | 自理或认知较需协助 | 能力较佳，可适应一般职场 |

**现实的建议顺序：** 多数具备「自理独立 + 情绪可控 + 能简单沟通」条件的孩子，小作所是最稳定的起点；能力较好的可在高三由职业重建人员评估是否尝试庇护工场或支持性就业。

**都要提早看。** 名额经常需要候补，而候补不会照你的毕业日期排。

## 二、关键角色：谁能帮你

| 角色 | 在哪里 | 能帮你什么 |
|------|--------|-----------|
| **特教老师 / 导师** | 学校 | IEP、日常教学调整、行为策略 |
| **转衔老师** | 学校（高中职阶段） | 毕业去向、转衔通报、与校外单位联系 |
| **学校社工 / 辅导老师** | 学校 | 家庭支持、资源转介 |
| **职业重建个案管理员** | 县市劳工主管机关 | 职业评量、就业方向媒合 |
| **就业服务员（就服员）** | 机构 / 就业服务单位 | 职场适应、现场支持 |
| **机构社工 / 个管员** | 小作所、日照、庇护工场 | 收案评估、日常服务规划 |
| **医院个管师 / 社工** | 医院 | 就医协助、资源转介、诊断证明流程 |
| **辅具中心人员** | 各县市辅具资源中心 | 沟通辅具、生活辅具的评估与补助 |

**一个实用的做法：** 把这些人的联系方式建成一个清单，存在手机里。**在需要的那一天，你不会有时间去查谁是谁。**

## 三、证明、鉴定与申请（查找关键字）

```text
【身心障碍证明】
  · 承办：户籍地公所 / 社会局（处）
  · 流程概要：先至公所提出申请 → 至指定医院鉴定 →
    需求评估 → 核发证明
  · ★ 注意「效期」与「重新鉴定」时程，过期会影响服务资格
  · 查找关键字：身心障碍鉴定 需求评估 + 县市名

【特殊教育鉴定与安置】
  · 承办：县市教育局（处）特殊教育科 / 鉴辅会
  · 高中职阶段：留意每年公告的「身心障碍学生适性辅导安置」简章
  · 查找关键字：适性辅导安置 简章 + 年度 + 县市名

【毕业转衔】
  · 学校端会进行转衔通报，衔接成人服务
  · ★ 主动确认：转衔数据有没有送出、送到哪里、谁承接

【预防接种受害救济】
  · 承办：卫生福利部相关审议机制
  · 性质：属于「无法排除关联」的社会补偿，
    不等同科学因果认定（第 5 章）
  · 查找关键字：预防接种受害救济

【经济与照顾支持】
  · 身心障碍者生活补助、辅具补助、交通补助
  · 临时及短期照顾（喘息服务）
  · 查找关键字：身心障碍 福利 + 县市名
```

## 四、沟通辅具（AAC）与视觉工具

```text
【最低成本的起点：自制图卡】
  · 六格需求图卡：我要喝水 / 我要上厕所 / 我不舒服 /
    我想休息 / 我做完了 / 我需要帮忙
  · 材料：打印 + 护贝 + 魔鬼毡（文具店都有）
  · ★ 用「实物照片」，不要用插图

【高端：平板沟通软件】
  · 市面上有多款中文 AAC 应用程序，功能与价格差异大
  · ★ 建议先由语言治疗师或辅具中心评估再购买
  · 免费替代方案：用图库创建「需求照片文件夹」也可以起步

【辅具补助】
  · 各县市辅具资源中心可协助评估与申请
  · 查找关键字：辅具资源中心 + 县市名

【视觉计时器】
  · 红色区块随时间消失的物理计时器
  · 网络可购得，价格不高，是本书最常用的单一工具
  · 替代方案：手机 App（但会伴随屏幕诱惑，实体较佳）
```

## 六、照顾者的资源

```text
【喘息】
  · 身心障碍者临时及短期照顾服务
  · 查找关键字：临时短期照顾 + 县市名

【心理支持】
  · 学校辅导室、医院社工
  · 各县市社区心理卫生中心
  · 若情绪困扰持续，身心科或心理咨商
  ★ 照顾者的忧郁是常见的，而且是可以处理的（第 11 章）

【家长团体】
  · 各障别的家长协会、地区性家长团体、在线社群
  · 价值：信息、经验、以及「不是只有我」这件事
  ★ 提醒：社群里分享得最多的通常是状况最严重的个案，
    那是社群的功能，不是母体的分布（第 2 章）
```

## 七、判断信息可信度的四个问题

网络上关于这个领域的信息极多，品质差异极大。用这四个问题筛：

```text
① 它有没有告诉你「这件事的证据强度」？
   → 把所有建议讲得同样肯定的，通常不可靠。

② 它的机转解释是不是过度精确？
   → 「补充 X 能提高 Y 的穿透率 Z%」这种说法，
     在缺乏引用时要打折。

③ 它会不会叫你不要看医生？
   → 任何暗示「这个方法可以取代医疗」的内容，直接关掉。

④ 它有没有在卖东西？
   → 不是说卖东西就不可信，但要知道那会影响论述。
```

**这四个问题，也适用于检验这本书。**
